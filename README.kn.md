## 📱 IndiaRealTime ಬಗ್ಗೆ

### ಸಮಸ್ಯೆ ಏನು

ಡೇಟಾ ಈಗಾಗಲೇ ಅಸ್ತಿತ್ವದಲ್ಲಿದೆ, ಹೆಚ್ಚಾಗಿ ಸಾರ್ವಜನಿಕವಾಗಿದೆ. ಅದು ಡಜನ್‌ಗಟ್ಟಲೆ ಬೇರೆ ಬೇರೆ ಸರ್ಕಾರಿ ಮತ್ತು PSU ಪೋರ್ಟಲ್‌ಗಳಲ್ಲಿ ಚದುರಿಹೋಗಿದೆ, ಪ್ರತಿಯೊಂದಕ್ಕೂ ಅದರದ್ದೇ ಫಾರ್ಮ್ಯಾಟ್, ಅಪ್‌ಡೇಟ್ ಆಗುವ ಸಮಯ, ಮತ್ತು (ಸಾಮಾನ್ಯವಾಗಿ) ವಿಶ್ವಾಸಾರ್ಹತೆಯ ಸಮಸ್ಯೆಗಳಿವೆ.

ಪಂಜಾಬ್‌ನಲ್ಲಿ ಮಂಡಿ ಬೆಲೆ ನೋಡಬಯಸುವ ರೈತನಿಗೆ Agmarknet ಎಂಬುದು ಇದೆ ಎಂದು ಗೊತ್ತಿರಬೇಕು. ಹೊರಗೆ ಹೋಗುವುದು ಸುರಕ್ಷಿತವೇ ಎಂದು ತಿಳಿಯಬಯಸುವ ಯಾರಿಗಾದರೂ CPCB ಬೇರೊಂದು ವೆಬ್‌ಸೈಟ್‌ನಲ್ಲಿ, ಬೇರೆ ಫಾರ್ಮ್ಯಾಟ್‌ನಲ್ಲಿ AQI ಪ್ರಕಟಿಸುತ್ತದೆ ಎಂದು ಗೊತ್ತಿರಬೇಕು. ಇಂಧನ ಬೆಲೆಗಳು ಪ್ರತಿದಿನ ಬದಲಾಗುತ್ತವೆ ಮತ್ತು ರಾಜ್ಯದಿಂದ ರಾಜ್ಯಕ್ಕೆ ಭಿನ್ನವಾಗಿರುತ್ತವೆ (ಬೇರೆ ಬೇರೆ VAT ದರಗಳು), ಆದರೆ ಪ್ರತಿ ತೈಲ ಕಂಪನಿಯು ತಾನು ಸೇವೆ ಒದಗಿಸುವ ನಗರಗಳಿಗೆ ಮಾತ್ರ, ಪ್ರತ್ಯೇಕವಾಗಿ, ತನ್ನದೇ ಸಂಖ್ಯೆಗಳನ್ನು ಪ್ರಕಟಿಸುತ್ತದೆ.

ಇದಕ್ಕೆ ಹೊಸ ಡೇಟಾ ಸಂಗ್ರಹಿಸುವ ಅಗತ್ಯವಿಲ್ಲ. ಈಗಾಗಲೇ ಸಾರ್ವಜನಿಕವಾಗಿರುವುದನ್ನು ತಂದು, ಫಾರ್ಮ್ಯಾಟ್‌ಗಳನ್ನು ಸಾಮಾನ್ಯಗೊಳಿಸಿ, ಮಂಡಿ ಬೆಲೆಗಳು, ಇಂಧನ ಬೆಲೆಗಳು, AQI, ಹವಾಮಾನ ಎಚ್ಚರಿಕೆಗಳು ಮುಂತಾದವುಗಳನ್ನು ಒಂದೇ ಕಡೆ ಇಡುವುದು ಅಗತ್ಯ, ಇದರಿಂದ ಒಬ್ಬ ವ್ಯಕ್ತಿ ಐದು ಬೇರೆ ಬೇರೆ ಸರ್ಕಾರಿ ಸೈಟ್‌ಗಳ ಐದು ಟ್ಯಾಬ್‌ಗಳನ್ನು ತೆರೆಯುವ ಬದಲು ಕೆಲವೇ ಸೆಕೆಂಡುಗಳಲ್ಲಿ ನೋಡಬಹುದು. **ಈ ಕೊರತೆಯನ್ನೇ IndiaRealTime ತುಂಬುತ್ತದೆ.**

### ನಾವು ಏನನ್ನು ಟ್ರ್ಯಾಕ್ ಮಾಡುತ್ತೇವೆ

| ವರ್ಗ | ಉದಾಹರಣೆಗಳು |
|---|---|
| ಬೆಲೆಗಳು | ಮಂಡಿ (ಕೃಷಿ ಉತ್ಪನ್ನ), ಇಂಧನ ಮತ್ತು LPG ರಾಜ್ಯ/ನಗರವಾರು, ಅಮೂಲ್ಯ ಲೋಹಗಳು, ಕರೆನ್ಸಿ ಪರಿವರ್ತನೆ, ಮ್ಯೂಚುಯಲ್ ಫಂಡ್ NAV, FD ದರಗಳು, ಟೋಲ್ ದರಗಳು |
| ಪರಿಸರ | ಗಾಳಿಯ ಗುಣಮಟ್ಟ (AQI, CPCB ಬ್ಯಾಂಡ್‌ಗಳು), ಹವಾಮಾನ ಎಚ್ಚರಿಕೆಗಳು, ಭೂಕಂಪ ಎಚ್ಚರಿಕೆಗಳು |
| ನಾಗರಿಕ / ಸಮಯ | ಬ್ಯಾಂಕ್ ರಜೆಗಳು, ಪಿನ್‌ಕೋಡ್ ಲುಕಪ್‌ಗಳು, ಟೈಮ್‌ಝೋನ್ ಪರಿವರ್ತನೆ |
| ಸಂಸ್ಕೃತಿ | ಪಂಚಾಂಗ ಮತ್ತು ಮುಹೂರ್ತ ಸಮಯಗಳು, ವ್ರತ ಕ್ಯಾಲೆಂಡರ್, ರಾಶಿಫಲ |
| ಕ್ರೀಡೆ | ಲೈವ್ ಕ್ರಿಕೆಟ್ ಸ್ಕೋರ್‌ಗಳು |

ಮೂಲ ಡೇಟಾ ಅನುಮತಿಸುವ ಕಡೆ ಕವರೇಜ್ ನಗರ/ರಾಜ್ಯ ಮಟ್ಟದಲ್ಲಿ ಸೂಕ್ಷ್ಮವಾಗಿದೆ. ಉದಾಹರಣೆಗೆ, ಇಂಧನ ಬೆಲೆಗಳನ್ನು ರಾಷ್ಟ್ರೀಯ ಸರಾಸರಿಯಾಗಿ ಅಲ್ಲ, ಪ್ರತಿ ನಗರಕ್ಕೂ ಪ್ರತ್ಯೇಕವಾಗಿ ಟ್ರ್ಯಾಕ್ ಮಾಡಲಾಗುತ್ತದೆ.

ಇದರ ಹಿಂದಿನ ಉಚಿತ ಭಾರತೀಯ ಡೇಟಾ API ಗಳ ಸಂಪೂರ್ಣ ಪಟ್ಟಿ, ಸೈಟ್ ಇನ್ನೂ ಬಳಸದ ಸರ್ಕಾರಿ API ಗಳ ಸಹಿತ, [API/](API/) ನಲ್ಲಿದೆ.

### ಸಂದರ್ಶಕರಿಗೆ ಇದು ಹೇಗೆ ಕೆಲಸ ಮಾಡುತ್ತದೆ

- **ಸ್ಥಳದ ಪ್ರಕಾರ ಬ್ರೌಸ್ ಮಾಡಿ**: URL ಗಳು `/state/city/category/` ಮಾದರಿಯನ್ನು ಅನುಸರಿಸುತ್ತವೆ (ಉದಾ. ಒಂದು ರಾಜ್ಯ ಪುಟ, ನಂತರ ಒಂದು ನಗರಕ್ಕೆ ಹೋಗುವುದು, ನಂತರ ಇಂಧನ ಬೆಲೆಗಳು ಅಥವಾ AQI ನಂತಹ ನಿರ್ದಿಷ್ಟ ವರ್ಗಕ್ಕೆ). ಹೆಚ್ಚಿನ ವರ್ಗಗಳು ರಾಷ್ಟ್ರೀಯ ಅವಲೋಕನ ಮತ್ತು ನಗರ-ನಿರ್ದಿಷ್ಟ ವಿವರ ಪುಟ ಎರಡೂ ರೂಪದಲ್ಲಿ ಇವೆ.
- **ಬೆಲೆಗಳನ್ನು ಹೋಲಿಸಿ**: ಒಂದು ಬೆಲೆ-ಹೋಲಿಕೆ ವ್ಯೂ ಒಂದು ವಸ್ತು ಅಥವಾ ಇಂಧನ ಪ್ರಕಾರವನ್ನು ನಗರಗಳು/ರಾಜ್ಯಗಳಾದ್ಯಂತ ಪಕ್ಕಪಕ್ಕದಲ್ಲಿ ತೋರಿಸುತ್ತದೆ, ಪ್ರತಿ ನಗರದ ಪುಟವನ್ನು ಪ್ರತ್ಯೇಕವಾಗಿ ತೆರೆಯುವ ಬದಲು.
- **ಕ್ಯಾಲ್ಕುಲೇಟರ್‌ಗಳು**: ಪ್ರತಿ-ಗ್ರಾಂ ಸಂಖ್ಯೆಯನ್ನು ಮಾತ್ರ ತೋರಿಸುವ ಬದಲು, ಒಂದು ಮೆಟಲ್ಸ್ ಕ್ಯಾಲ್ಕುಲೇಟರ್ ಲೈವ್ ಚಿನ್ನ/ಬೆಳ್ಳಿ ದರಗಳನ್ನು ತೂಕ ಮತ್ತು ಶುದ್ಧತೆಗೆ ಅನುಗುಣವಾಗಿ ಪರಿವರ್ತಿಸುತ್ತದೆ.
- **ಶೇರ್ ಕಾರ್ಡ್‌ಗಳು**: ಡೇಟಾ ಪುಟಗಳು ಸಾಮಾಜಿಕ ವೇದಿಕೆಗಳಿಗೆ ಸೂಕ್ತ ಗಾತ್ರದ ಶೇರ್ ಮಾಡಬಹುದಾದ ಇಮೇಜ್ ಕಾರ್ಡ್ (ಬೆಲೆ, ದಿನಾಂಕ, ಮೂಲ) ರಚಿಸುತ್ತವೆ, ಇದರಿಂದ ಸ್ಕ್ರೀನ್‌ಶಾಟ್ ಇಲ್ಲದೆಯೇ ಒಂದು ಸಂಗತಿಯನ್ನು ಹಂಚಿಕೊಳ್ಳಬಹುದು.
- **ಲೇಖಕರ ಹಬ್**: ಪ್ರತಿ ಲೇಖನಕ್ಕೂ ಒಬ್ಬ ನಿಜವಾದ ಲೇಖಕನ ಹೆಸರು, ಅವರ ಪ್ರೊಫೈಲ್ ಪುಟದೊಂದಿಗೆ, ಕ್ರೆಡಿಟ್ ನೀಡಲಾಗುತ್ತದೆ, ಅನಾಮಧೇಯ ಬೈಲೈನ್ ಅಲ್ಲ. `/authors/` ಎಲ್ಲರನ್ನೂ ಪಟ್ಟಿ ಮಾಡುತ್ತದೆ, `/author/<name>/` ಅವರ ಪ್ರಕಟಿತ ಕೆಲಸವನ್ನು ತೋರಿಸುತ್ತದೆ.

ಭಾರತದಲ್ಲಿ ಹೆಚ್ಚಿನ "ಲೈವ್ ಡೇಟಾ" ಸೈಟ್‌ಗಳು ದಿನಕ್ಕೊಮ್ಮೆ ಸ್ಕ್ರ್ಯಾಪ್ ಮಾಡಿ ಅದನ್ನು ರಿಯಲ್-ಟೈಮ್ ಎಂದು ಕರೆಯುತ್ತವೆ, ಇಲ್ಲವೇ ಅದು ನಿರ್ವಹಿಸಲಾಗದಷ್ಟು ಆಗುವವರೆಗೂ ಒಂದು ಪೇಜ್-ಬಿಲ್ಡರ್ ಥೀಮ್‌ಗೆ ಡಜನ್‌ಗಟ್ಟಲೆ ಅಸಂಬಂಧಿತ ವಿಜೆಟ್‌ಗಳನ್ನು ಸೇರಿಸುತ್ತಲೇ ಇರುತ್ತವೆ. IndiaRealTime ಸುಮಾರು 15 ಬೇರೆ ಬೇರೆ ಸಾರ್ವಜನಿಕ ಡೇಟಾ ಮೂಲಗಳಿಂದ (ಸರ್ಕಾರಿ API ಗಳು, ಎಕ್ಸ್‌ಚೇಂಜ್‌ಗಳು, ಹವಾಮಾನ ಮತ್ತು ಭೂಕಂಪ ಫೀಡ್‌ಗಳು) ಡೇಟಾ ತೆಗೆದುಕೊಂಡು ಪ್ರತಿಯೊಂದನ್ನೂ ಒಂದು ಮೊನೊಲಿತ್ ಬದಲಿಗೆ ಅದರದೇ ಸಣ್ಣ, ಪರೀಕ್ಷಿಸಬಹುದಾದ ಘಟಕವಾಗಿ ಪರಿವರ್ತಿಸುತ್ತದೆ.

ನೀವು ಡೇಟಾ-ಅಗ್ರಿಗೇಶನ್ ಸೈಟ್, ಪ್ಲಗಿನ್-ಆಧಾರಿತ ಆರ್ಕಿಟೆಕ್ಚರ್, ಅಥವಾ "ಅಪ್‌ಸ್ಟ್ರೀಮ್ API ಕೊನೆಗೆ ಮೋಸ ಮಾಡುತ್ತದೆ" ಎಂಬುದು ನಿಜವಾದ ವಿನ್ಯಾಸ ಮಿತಿಯಾಗಿರುವ ಯಾವುದನ್ನಾದರೂ ನಿರ್ಮಿಸುತ್ತಿದ್ದರೆ, ಇದು ನಿಮಗಾಗಿಯೇ ಬರೆಯಲಾಗಿದೆ.

### ತಾಂತ್ರಿಕ ರೇಖಾಚಿತ್ರ

```
Public data sources (govt APIs, exchanges, weather/seismic feeds, ~15 total)
        │
        ▼
One WordPress plugin per source  ──►  WP-Cron fetch on its own schedule
  (fetch → validate → normalize)       (e.g. every 6h for commodities/AQI,
        │                               daily for fuel prices)
        ▼
WP transient cache (MySQL-backed)  ◄── on fetch failure, keep serving the
        │                               last good cached value instead of
        ▼                               erroring or showing nothing
Custom theme templates (PHP)
  render location/category pages
        │
        ▼
irt-dataset-schema → schema.org JSON-LD  +  irt-api-health-monitor watches
  (machine-readable structured data)       all fetchers from one dashboard
        │
        ▼
IndexNow ping on update → search engines re-crawl fresh data within minutes,
  not on their own schedule
```

### ವಿನ್ಯಾಸ ತತ್ವಶಾಸ್ತ್ರ

**ಪ್ರತಿ ಡೇಟಾ ಮೂಲವೂ ಒಂದು ಸಂಪೂರ್ಣ ಸ್ವತಂತ್ರ ಪ್ಲಗಿನ್**, ಹಂಚಿಕೆಯ ಇಂಜೆಶನ್ ಪೈಪ್‌ಲೈನ್ ಅಲ್ಲ. ಒಂದು ಪ್ಲಗಿನ್‌ಗೆ ಅದರದೇ ಫೆಚ್ ವೇಳಾಪಟ್ಟಿ, ಕ್ಯಾಶ್, ಮತ್ತು ವೈಫಲ್ಯ ನಿರ್ವಹಣೆ ಇರುತ್ತದೆ. ಯಾವುದೇ ಸರ್ಕಾರಿ API ತನ್ನ ರೆಸ್ಪಾನ್ಸ್ ಫಾರ್ಮ್ಯಾಟ್ ಬದಲಿಸಿದರೆ ಅಥವಾ ಡೌನ್ ಆದರೆ, ನಿಖರವಾಗಿ ಒಂದು ಪ್ಲಗಿನ್ ಮಾತ್ರ ಒಡೆಯುತ್ತದೆ. ಉಳಿದ ~19 ಸೇವೆ ನೀಡುವುದನ್ನು ಮುಂದುವರಿಸುತ್ತವೆ. ಇಷ್ಟೊಂದು ಸ್ವತಂತ್ರ ಚಲಿಸುವ ಭಾಗಗಳಿದ್ದಾಗ, ಪ್ರತಿ ಪ್ಲಗಿನ್‌ನ ಲಾಗ್‌ಗಳನ್ನು ಕೈಯಾರೆ ಪರಿಶೀಲಿಸುವ ಬದಲು ಎಲ್ಲವನ್ನೂ ಒಂದೇ ಕಡೆಯಿಂದ ಗಮನಿಸುವ ವ್ಯವಸ್ಥೆ ಬೇಕಾಗುತ್ತದೆ, ಆದ್ದರಿಂದಲೇ `irt-api-health-monitor` ಇದೆ.

### ಸ್ಟ್ಯಾಕ್

- **WordPress** (ಕಸ್ಟಮ್ ಥೀಮ್, ಪೇಜ್ ಬಿಲ್ಡರ್ ಇಲ್ಲ): PHP ಟೆಂಪ್ಲೇಟ್‌ಗಳು, ವೆನಿಲ್ಲಾ JS/CSS
- **~20 ಕಸ್ಟಮ್ ಪ್ಲಗಿನ್‌ಗಳು**, ಪ್ರತಿ ಡೇಟಾ ಮೂಲಕ್ಕೆ ಒಂದು, ಪ್ರತಿಯೊಂದಕ್ಕೂ ಅದರದೇ ಫೆಚ್/ಕ್ಯಾಶ್ ಲೇಯರ್
- ಸಂಗ್ರಹಣೆ ಮತ್ತು ಟ್ರಾನ್ಸಿಯಂಟ್ ಕ್ಯಾಶಿಂಗ್‌ಗೆ **MySQL**; ಲೋಕಲ್ ಡೆವ್‌ಗೆ Docker Compose
- ಒಂದು ಮೀಸಲಾದ ಪ್ಲಗಿನ್ (`irt-dataset-schema`) ಮೂಲಕ Schema.org ರಚನಾತ್ಮಕ ಡೇಟಾ
- ಡೇಟಾ ಅಪ್‌ಡೇಟ್‌ಗಳ ಮೇಲೆ ತಕ್ಷಣದ ಸರ್ಚ್ ಎಂಜಿನ್ ಇಂಡೆಕ್ಸಿಂಗ್‌ಗೆ IndexNow ಇಂಟಿಗ್ರೇಶನ್

### ನೈಜ ಜೀವನದ ಇಂಟಿಗ್ರೇಶನ್ ಉದಾಹರಣೆಗಳು

#### ಉದಾಹರಣೆ 1: ಮಂಡಿ ಬೆಲೆ ಪರಿಶೀಲಿಸುವ ರೈತ (CLI)
```bash
# Get wheat prices in Punjab
$ indiarealtime mandi --commodity wheat --state Punjab

Commodity  Market           State         City      Price (₹)  Unit
wheat      APMC Ludhiana    Punjab        Ludhiana  2450       Quintal
wheat      APMC Amritsar    Punjab        Amritsar  2420       Quintal
```

#### ಉದಾಹರಣೆ 2: ಪ್ರೈಸ್ ಅಲರ್ಟ್ ಬಾಟ್ ನಿರ್ಮಿಸುತ್ತಿರುವ ಸ್ಟಾರ್ಟಪ್ (Python)
```python
from indiarealtime import IndiaRealTime

irt = IndiaRealTime()

# Get current wheat prices
prices = irt.mandi_prices(commodity="wheat", state="Punjab", limit=5)

for price in prices:
    print(f"📊 {price.market}: ₹{price.price}/{price.unit}")
    
    # Alert if price drops below ₹2400
    if price.price < 2400:
        send_sms_alert(f"Wheat at {price.market} is ₹{price.price}!")
```

#### ಉದಾಹರಣೆ 3: ಇಂಧನ ಬೆಲೆ ಪರಿಶೀಲಿಸುವ ಡೆಲಿವರಿ ಆ್ಯಪ್ (REST API)
```javascript
// Fetch fuel prices for driver earnings calculation
fetch('http://localhost:5000/v1/fuel/prices?state=Maharashtra&type=diesel')
  .then(r => r.json())
  .then(data => {
    data.results.forEach(price => {
      console.log(`Diesel in ${price.city}: ₹${price.price}/L`);
    });
  });
```

#### ಉದಾಹರಣೆ 4: AQI ಸ್ಕ್ರ್ಯಾಪ್ ಮಾಡುವ ನ್ಯೂಸ್ ವೆಬ್‌ಸೈಟ್ (Python)
```python
from indiarealtime import IndiaRealTime
import requests

irt = IndiaRealTime()
aqi = irt.air_quality(city="Delhi")

if aqi[0].aqi > 300:
    # Post alert headline
    headline = f"🚨 Air Quality SEVERE in {aqi[0].city}: AQI {aqi[0].aqi}"
    post_to_website(headline)
```

#### ಉದಾಹರಣೆ 5: ದರಗಳನ್ನು ತೋರಿಸುವ ಫೈನಾನ್ಸ್ ಡ್ಯಾಶ್‌ಬೋರ್ಡ್ (React)
```jsx
import { useState, useEffect } from 'react';

function CurrencyRates() {
  const [rates, setRates] = useState({});
  
  useEffect(() => {
    fetch('/api/v1/finance/currency?base=INR&symbols=USD,EUR,GBP')
      .then(r => r.json())
      .then(d => setRates(d.rates));
  }, []);
  
  return (
    <div>
      <h2>INR Exchange Rates</h2>
      <p>1 INR = ${rates.USD?.toFixed(4)} USD</p>
      <p>1 INR = €{rates.EUR?.toFixed(4)} EUR</p>
    </div>
  );
}
```

### ಎಂಜಿನಿಯರಿಂಗ್ ನಿರ್ಧಾರಗಳು ಮತ್ತು ಪಾಠಗಳು

ಈ ಪ್ರತಿಯೊಂದು ಸವಾಲೂ ತನ್ನದೇ ಪುಟ ಪಡೆಯುವಷ್ಟು ದೊಡ್ಡದಾಯಿತು:

- **[ಉದ್ದೇಶಪೂರ್ವಕವಾಗಿ ಹಳೆಯ ಡೇಟಾ ನೀಡುವುದು](notes/stale-cache-fallback.md)**: ಸರ್ಕಾರಿ ಮತ್ತು ಎಕ್ಸ್‌ಚೇಂಜ್ API ಗಳು ವಿಶ್ವಾಸಾರ್ಹವಲ್ಲ, ಆದರೂ ಸೈಟ್ ವಿಶ್ವಾಸಾರ್ಹವಾಗಿ ಕಾಣಬೇಕು. ಒಂದು ಅಪ್‌ಸ್ಟ್ರೀಮ್ API ವಿಫಲವಾದಾಗ, ನಾವು ಎರರ್ ನೀಡುವ ಅಥವಾ ಏನೂ ತೋರಿಸದಿರುವ ಬದಲು ಕೊನೆಯ ಒಳ್ಳೆಯ ಕ್ಯಾಶ್ ಮಾಡಿದ ಮೌಲ್ಯವನ್ನು ನೀಡುತ್ತೇವೆ.
- **[ಪ್ರವೇಶಿಸುವಿಕೆ ಮತ್ತು ಬಣ್ಣ, ಎರಡೂ ಮುಖ್ಯ](notes/cvd-safe-aqi-colors.md)**: ಡೇಟಾ ಎಲ್ಲರಿಗೂ ಪ್ರವೇಶಿಸಬಹುದಾಗಿರುವಂತೆ ಪ್ರತಿ ಸಿಮ್ಯಾಂಟಿಕ್ ಬಣ್ಣವನ್ನೂ WCAG ಕಾಂಟ್ರಾಸ್ಟ್ ಮತ್ತು ಕಲರ್-ವಿಷನ್-ಡೆಫಿಷಿಯನ್ಸಿ ಸಿಮ್ಯುಲೇಶನ್ ವಿರುದ್ಧ ಪರೀಕ್ಷಿಸಲಾಗುತ್ತದೆ.
- **[ಎರಡು ಭಾಷೆಗಳಲ್ಲಿ ಒಪ್ಪುವ ಹ್ಯಾಶ್](notes/cross-language-hash-parity.md)**: PHP ಮತ್ತು JavaScript ಇಂಟಿಜರ್ ಓವರ್‌ಫ್ಲೋ ಬಗ್ಗೆ ಒಪ್ಪುವುದಿಲ್ಲ, ಆದರೂ ಲೇಖಕ ಆಟ್ರಿಬ್ಯೂಶನ್ ಅವು ಒಪ್ಪುವುದನ್ನೇ ಅವಲಂಬಿಸಿದೆ.
- **[ಪ್ರತಿ ರಾಜ್ಯಕ್ಕೂ ರೀರೈಟ್-ರೂಲ್ regex ಇಲ್ಲದೆ ಲೊಕೇಶನ್ ರೂಟಿಂಗ್](notes/location-routing-without-regex.md)**: ಪ್ರತಿ ಪ್ರದೇಶಕ್ಕೂ ಒಂದು ರೀರೈಟ್ ರೂಲ್ ಬದಲಿಗೆ ಪ್ರತಿ ರಾಜ್ಯ ಮತ್ತು ನಗರ ಪುಟಕ್ಕೂ ಒಂದೇ ರೂಟಿಂಗ್ ಮಾರ್ಗ.
- **[~20 ಪ್ಲಗಿನ್‌ಗಳು ಒಂದು ನಿರ್ವಹಣಾ ಬಾಜಿ, ಉಚಿತ ಊಟವಲ್ಲ](notes/plugin-per-source-tradeoff.md)**: ದೋಷ ಪ್ರತ್ಯೇಕತೆಯ ಬೆಲೆ ಎಂದರೆ ಎಲ್ಲವನ್ನೂ ಸ್ಥಿರವಾಗಿಡಲು ಬೇಕಾದ ಹೆಚ್ಚಿನ ಮೇಲ್ಮೈ ವಿಸ್ತೀರ್ಣ.

## 👋 ಲೇಖಕರ ಬಗ್ಗೆ

ಈ ರೆಪೊಸಿಟರಿ ಪ್ರಾಜೆಕ್ಟ್‌ನ ಒಂದು ಅವಲೋಕನ, ಸೈಟ್‌ನ ಮೂಲವಲ್ಲ. WordPress ಕೋಡ್‌ಬೇಸ್ ಸದ್ಯಕ್ಕೆ ಮುಚ್ಚಿದೆ. ಆದರೆ, [API ಪಟ್ಟಿ](API/) ಮತ್ತು `scripts/` ಫೋಲ್ಡರ್ PR ಗಳಿಗೆ ತೆರೆದಿವೆ - ಕಾಣೆಯಾದ API ಗಳು, ತಿದ್ದುಪಡಿಗಳು, ಫೆಚ್‌ನ ಇನ್ನಷ್ಟು ಉದಾಹರಣೆಗಳು, ಎಲ್ಲವೂ ಸ್ವಾಗತಾರ್ಹ.

ಮೇಲಿನ ಯಾವುದೇ ಸಮಸ್ಯೆಗಳ ಒಂದು ಆವೃತ್ತಿಯನ್ನು ನೀವು ಪರಿಹರಿಸಿದ್ದರೆ (ಸ್ಟೇಲ್-ಕ್ಯಾಶ್ ಫಾಲ್‌ಬ್ಯಾಕ್ ತಂತ್ರಗಳು, ಪ್ಲಗಿನ್-ಪರ್-ಸೋರ್ಸ್ ಆರ್ಕಿಟೆಕ್ಚರ್‌ಗಳು, CVD-ಸೇಫ್ ಕಲರ್ ಸಿಸ್ಟಂಗಳು, ಕ್ರಾಸ್-ಲ್ಯಾಂಗ್ವೇಜ್ ಹ್ಯಾಶ್ ಪ್ಯಾರಿಟಿ), ಅಥವಾ ನೀವು ಈಗ ಅದೇ ಗೋಡೆಗೆ ಡಿಕ್ಕಿ ಹೊಡೆಯುತ್ತಿದ್ದರೆ, ಒಂದು [ಚರ್ಚೆಯನ್ನು](https://github.com/padmarajnidagundi/indiarealtime-com/issues) ತೆರೆಯಿರಿ. ನಾನು ನಿಜವಾಗಿಯೂ ಟಿಪ್ಪಣಿಗಳನ್ನು ಹೋಲಿಸಲು ಬಯಸುತ್ತೇನೆ.

**ಕೊಡುಗೆಗಳಿಗೆ ಸ್ವಾಗತ:** ಹೊಸ ಡೇಟಾ ಮೂಲಗಳನ್ನು ಪ್ಲಗಿನ್‌ಗಳಾಗಿ ಹೇಗೆ ಸೇರಿಸುವುದು ಎಂಬುದಕ್ಕೆ [CONTRIBUTING.md](CONTRIBUTING.md) ನೋಡಿ, ಅಥವಾ ಸಹಾಯ ಮಾಡುವ ಇತರ ವಿಧಾನಗಳಿಗೆ [CONTRIBUTORS_GUIDE.md](CONTRIBUTORS_GUIDE.md) ನೋಡಿ.

ನಿಮಗೆ ಪ್ರಶ್ನೆಗಳು ಅಥವಾ ಆಲೋಚನೆಗಳಿದ್ದರೆ, [GitHub Issues](https://github.com/padmarajnidagundi/indiarealtime-com/issues) ಅಥವಾ ಇಮೇಲ್ ಮೂಲಕ ಸಂಪರ್ಕಿಸಿ.
