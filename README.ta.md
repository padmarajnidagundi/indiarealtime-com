### பிரச்சனை என்ன

தரவு ஏற்கனவே உள்ளது, பெரும்பாலும் பொதுவெளியில் உள்ளது. அது வெவ்வேறு அரசு, PSU போர்ட்டல்களில் சிதறிக் கிடக்கிறது, ஒவ்வொன்றுக்கும் அதன் சொந்த வடிவமைப்பு, புதுப்பிப்பு நேரம், (பெரும்பாலும்) நம்பகத்தன்மைப் பிரச்சனைகள் உண்டு.

பஞ்சாபில் மண்டி விலைகளைப் பார்க்க விரும்பும் ஒரு விவசாயிக்கு Agmarknet என்று ஒன்று இருக்கிறது என்பது தெரிந்திருக்க வேண்டும். வெளியே செல்வது பாதுகாப்பானதா என அறிய விரும்பும் ஒருவருக்கு CPCB வேறு இணையதளத்தில், வேறு வடிவமைப்பில் AQI-ஐ வெளியிடுகிறது என்பது தெரிந்திருக்க வேண்டும். எரிபொருள் விலைகள் தினமும் மாறுகின்றன, மாநிலத்திற்கு மாநிலம் வேறுபடுகின்றன (வேறு VAT விகிதங்கள்), ஆனால் ஒவ்வொரு எண்ணெய் நிறுவனமும் தான் சேவை செய்யும் நகரங்களுக்கு மட்டும், தனித்தனியாக, தன் சொந்த எண்களை மட்டுமே வெளியிடுகிறது.

இதற்குப் புதிய தரவு எதுவும் சேகரிக்க வேண்டியதில்லை. ஏற்கனவே பொதுவெளியில் உள்ளதை எடுத்து, வடிவமைப்புகளை ஒருங்கிணைத்து, மண்டி விலைகள், எரிபொருள் விலைகள், AQI, வானிலை எச்சரிக்கைகள் போன்றவற்றை ஒரே இடத்தில் வைப்பது தேவை, இதனால் ஒருவர் ஐந்து வெவ்வேறு அரசு தளங்களின் ஐந்து டேப்களைத் திறப்பதற்குப் பதிலாக சில வினாடிகளில் பார்க்க முடியும். **இந்த இடைவெளியையே IndiaRealTime நிரப்புகிறது.**

> "என் குழந்தைகளை வெளியே விளையாட அனுப்புவதற்கு முன் AQI-ஐப் பார்க்க வேண்டும். முன்பு 5 வெவ்வேறு மூலங்களை கூகிள் செய்வேன் - Agmarknet, CPCB, வானிலை தளங்கள் - எல்லாம் வெவ்வேறு வடிவமைப்பில். இப்போது ஒரே க்ளிக்கில் வெளியே செல்வது பாதுகாப்பானதா எனத் தெரிந்துகொள்கிறேன்."

### நாங்கள் என்ன கண்காணிக்கிறோம்

| வகை | எடுத்துக்காட்டுகள் |
|---|---|
| விலைகள் | மண்டி (விவசாய பொருட்கள்), எரிபொருள் & LPG மாநிலம்/நகரம் வாரியாக, விலையுயர்ந்த உலோகங்கள், நாணய மாற்று, மியூச்சுவல் ஃபண்ட் NAV-கள், FD விகிதங்கள், டோல் விகிதங்கள் |
| சூழல் | காற்று தரம் (AQI, CPCB பட்டைகள்), வானிலை எச்சரிக்கைகள், நிலநடுக்க எச்சரிக்கைகள் |
| குடிமை / நேரம் | வங்கி விடுமுறைகள், பின்கோடு தேடல்கள், நேர மண்டல மாற்று |
| பண்பாடு | பஞ்சாங்கம் & முகூர்த்த நேரங்கள், விரத நாட்காட்டி, ராசிபலன் |
| விளையாட்டு | நேரடி கிரிக்கெட் ஸ்கோர்கள் |

அடிப்படைத் தரவு அனுமதிக்கும் இடங்களில் கவரேஜ் நகரம்/மாநில அளவில் நுணுக்கமாக உள்ளது. எடுத்துக்காட்டாக, எரிபொருள் விலைகள் தேசிய சராசரியாக அல்லாமல் ஒவ்வொரு நகரத்திற்கும் தனித்தனியாகக் கண்காணிக்கப்படுகின்றன.

இதன் பின்னணியில் உள்ள இலவச இந்திய தரவு API-களின் முழுப் பட்டியல், தளம் இன்னும் பயன்படுத்தாத அரசு API-களுடன், [API/](API/)-இல் உள்ளது.

### பார்வையாளர்களுக்கு இது எப்படி வேலை செய்கிறது

- **இருப்பிடத்தின்படி உலாவவும்**: URL-கள் `/state/city/category/` முறையைப் பின்பற்றுகின்றன (எ.கா. ஒரு மாநிலப் பக்கம், அதன் பின் ஒரு நகரத்திற்குச் செல்லுதல், அதன் பின் எரிபொருள் விலைகள் அல்லது AQI போன்ற ஒரு குறிப்பிட்ட தரவு வகைக்குச் செல்லுதல்). பெரும்பாலான வகைகள் தேசிய கண்ணோட்டமாகவும், நகர-குறிப்பிட்ட விவரப் பக்கமாகவும் இரண்டு வடிவங்களிலும் உள்ளன.
- **விலைகளை ஒப்பிடவும்**: ஒரு விலை-ஒப்பீட்டுக் காட்சி ஒரு பொருள் அல்லது எரிபொருள் வகையை நகரங்கள்/மாநிலங்களில் பக்கத்திற்குப் பக்கம் காட்டுகிறது, ஒவ்வொரு நகரப் பக்கத்தையும் தனித்தனியாகத் திறப்பதற்குப் பதிலாக.
- **கால்குலேட்டர்கள்**: ஒரு உலோக கால்குலேட்டர் ஒரு கிராம் விலையை மட்டும் காட்டுவதற்குப் பதிலாக, நேரடி தங்கம்/வெள்ளி விகிதங்களை எடை மற்றும் தூய்மைக்கு ஏற்ப மாற்றுகிறது.
- **பகிர்வு அட்டைகள்**: தரவுப் பக்கங்கள் சமூக ஊடகங்களுக்கு ஏற்ற அளவிலான பகிரக்கூடிய படக் கார்டை (விலை, தேதி, மூலம்) உருவாக்குகின்றன, இதனால் ஸ்கிரீன்ஷாட் இல்லாமலேயே ஒரு தகவலைப் பகிரலாம்.
- **ஆசிரியர் மையம்**: ஒவ்வொரு கட்டுரையும் பெயர் தெரியாத பைலைன் இல்லாமல், சுயவிவரப் பக்கத்துடன் ஒரு உண்மையான ஆசிரியருக்குப் பெருமை சேர்க்கப்படுகிறது. `/authors/` அனைவரையும் பட்டியலிடுகிறது, `/author/<name>/` அவர்களின் வெளியிடப்பட்ட படைப்புகளைக் காட்டுகிறது.

## 🏗️ வெப் பயன்பாட்டின் கட்டமைப்பு

இந்தியாவில் பெரும்பாலான "நேரடி தரவு" தளங்கள் ஒன்று நாளொன்றுக்கு ஒருமுறை ஸ்கிரேப் செய்து அதை நேரடி நேரம் என்று அழைக்கின்றன, அல்லது அது பராமரிக்க முடியாத அளவுக்கு ஒரு பேஜ்-பில்டர் தீமில் தொடர்பில்லாத விட்ஜெட்களைச் சேர்த்துக்கொண்டே இருக்கும். IndiaRealTime சுமார் 15 வெவ்வேறு பொது தரவு மூலங்களில் (அரசு API-கள், பரிவர்த்தனைகள், வானிலை மற்றும் நிலநடுக்க ஊட்டங்கள்) இருந்து தரவைப் பெற்று, ஒவ்வொன்றையும் ஒரு பெருந்தொகுதிக்குப் பதிலாக அதன் சொந்த சிறிய, சோதிக்கக்கூடிய அலகாக மாற்றுகிறது.

நீங்கள் ஒரு தரவு-திரட்டல் தளம், செருகுநிரல்-அடிப்படையிலான கட்டமைப்பு, அல்லது "அப்ஸ்ட்ரீம் API இறுதியில் உங்களை ஏமாற்றும்" என்பது ஒரு உண்மையான வடிவமைப்புத் தடையாக உள்ள எதையாவது உருவாக்குகிறீர்கள் என்றால், இது உங்களுக்காகவே எழுதப்பட்டது.

### தொழில்நுட்ப வரைபடம்

```
Public data sources (govt APIs, exchanges, weather/seismic feeds, ~15 total)
        │
        ▼
One WordPress plugin per source  ──►  WP-Cron fetch on its own schedule
  (fetch → validate → normalize)       (e.g. every 6h for commodities/AQI,
        │                               daily for fuel prices)
        ▼
WP transient cache (MySQL-backed)  ◄── on fetch failure, keep serving the
        │                               last good cached value instead of
        ▼                               erroring or showing nothing
Custom theme templates (PHP)
  render location/category pages
        │
        ▼
irt-dataset-schema → schema.org JSON-LD  +  irt-api-health-monitor watches
  (machine-readable structured data)       all fetchers from one dashboard
        │
        ▼
IndexNow ping on update → search engines re-crawl fresh data within minutes,
  not on their own schedule
```

### வடிவமைப்புத் தத்துவம்

**ஒவ்வொரு தரவு மூலமும் ஒரு முழுமையான சுயாதீன செருகுநிரல்**, பகிரப்பட்ட உள்வாங்கல் பைப்லைன் அல்ல. ஒரு செருகுநிரலுக்கு அதன் சொந்த பெறுதல் அட்டவணை, கேச், மற்றும் தோல்வி கையாளுதல் உண்டு. ஏதேனும் அரசு API தன் பதில் வடிவமைப்பை மாற்றினாலோ அல்லது செயலிழந்தாலோ, சரியாக ஒரு செருகுநிரல் மட்டுமே உடையும். மீதமுள்ள ~19 சேவையளிப்பதைத் தொடரும். இத்தனை சுயாதீன அசையும் பாகங்களுடன், ஒவ்வொரு செருகுநிரலின் பதிவுகளையும் கையால் சரிபார்ப்பதற்குப் பதிலாக அனைத்தையும் ஒரே இடத்திலிருந்து கண்காணிக்கும் ஒரு அமைப்பு தேவை என்பதால்தான் `irt-api-health-monitor` உள்ளது.

### தொழில்நுட்ப அடுக்கு

- **WordPress** (தனிப்பயன் தீம், பேஜ் பில்டர் இல்லை): PHP டெம்ப்ளேட்கள், வெனிலா JS/CSS

#### எடுத்துக்காட்டு 1: மண்டி விலைகளைப் பார்க்கும் விவசாயி (CLI)
```bash
# Get wheat prices in Punjab
$ indiarealtime mandi --commodity wheat --state Punjab

Commodity  Market           State         City      Price (₹)  Unit
wheat      APMC Ludhiana    Punjab        Ludhiana  2450       Quintal
wheat      APMC Amritsar    Punjab        Amritsar  2420       Quintal
```

#### எடுத்துக்காட்டு 2: விலை எச்சரிக்கை பாட் உருவாக்கும் ஸ்டார்ட்அப் (Python)
```python
from indiarealtime import IndiaRealTime

irt = IndiaRealTime()

# Get current wheat prices
prices = irt.mandi_prices(commodity="wheat", state="Punjab", limit=5)

for price in prices:
    print(f"📊 {price.market}: ₹{price.price}/{price.unit}")
    
    # Alert if price drops below ₹2400
    if price.price < 2400:
        send_sms_alert(f"Wheat at {price.market} is ₹{price.price}!")
```

#### எடுத்துக்காட்டு 3: எரிபொருள் விலைகளைச் சரிபார்க்கும் டெலிவரி ஆப் (REST API)
```javascript
// Fetch fuel prices for driver earnings calculation
fetch('http://localhost:5000/v1/fuel/prices?state=Maharashtra&type=diesel')
  .then(r => r.json())
  .then(data => {
    data.results.forEach(price => {
      console.log(`Diesel in ${price.city}: ₹${price.price}/L`);
    });
  });
```

#### எடுத்துக்காட்டு 4: AQI-ஐ ஸ்கிரேப் செய்யும் செய்தி இணையதளம் (Python)
```python
from indiarealtime import IndiaRealTime
import requests

irt = IndiaRealTime()
aqi = irt.air_quality(city="Delhi")

if aqi[0].aqi > 300:
    # Post alert headline
    headline = f"🚨 Air Quality SEVERE in {aqi[0].city}: AQI {aqi[0].aqi}"
    post_to_website(headline)
```

#### எடுத்துக்காட்டு 5: விகிதங்களைக் காட்டும் நிதி டாஷ்போர்டு (React)
```jsx
import { useState, useEffect } from 'react';

function CurrencyRates() {
  const [rates, setRates] = useState({});
  
  useEffect(() => {
    fetch('/api/v1/finance/currency?base=INR&symbols=USD,EUR,GBP')
      .then(r => r.json())
      .then(d => setRates(d.rates));
  }, []);
  
  return (
    <div>
      <h2>INR Exchange Rates</h2>
      <p>1 INR = ${rates.USD?.toFixed(4)} USD</p>
      <p>1 INR = €{rates.EUR?.toFixed(4)} EUR</p>
    </div>
  );
}
```

### நீங்களே முயற்சிக்கவும்

`scripts/fetch-pincode.js` என்பது தளத்தின் செருகுநிரல்கள் பயன்படுத்தும் பெறுதல்-மற்றும்-ஒருங்கிணைப்பு முறையின் ஒரு சிறிய தனித்த எடுத்துக்காட்டு, மேலே உள்ள பட்டியலில் இருந்து சாவி தேவையில்லாத ஒரு API-இல் பயன்படுத்தப்பட்டது:

```
node scripts/fetch-pincode.js 560001
```

### பொறியியல் முடிவுகள் & பாடங்கள்

இந்தச் சவால்கள் ஒவ்வொன்றும் அதற்கென தனிப் பக்கம் தேவைப்படும் அளவுக்கு நீண்டுவிட்டது:

- **[வேண்டுமென்றே பழைய தரவை வழங்குதல்](notes/stale-cache-fallback.md)**: அரசு மற்றும் பரிவர்த்தனை API-கள் நம்பகமானவை அல்ல, ஆனாலும் தளம் நம்பகமானதாகத் தோன்ற வேண்டும். ஒரு அப்ஸ்ட்ரீம் API தோல்வியடையும்போது, பிழை காட்டுவதற்கு அல்லது எதுவும் காட்டாமல் இருப்பதற்குப் பதிலாக நாங்கள் கடைசி நல்ல கேச் செய்யப்பட்ட மதிப்பை வழங்குகிறோம்.
- **[அணுகல்தன்மையும் நிறமும், இரண்டும் முக்கியம்](notes/cvd-safe-aqi-colors.md)**: தரவு அனைவருக்கும் அணுகக்கூடியதாக இருக்க ஒவ்வொரு அர்த்தப்பூர்வமான நிறமும் WCAG மாறுபாடு மற்றும் நிற-பார்வை-குறைபாடு உருவகப்படுத்துதலுக்கு எதிராகச் சோதிக்கப்படுகிறது.
- **[இரு மொழிகளிலும் ஒத்துப்போகும் ஹாஷ்](notes/cross-language-hash-parity.md)**: PHP-யும் JavaScript-உம் இன்டிஜர் ஓவர்ஃப்ளோவில் உடன்படுவதில்லை, ஆனாலும் ஆசிரியர் பெருமையளிப்பு அவை உடன்படுவதையே சார்ந்துள்ளது.
- **[ஒவ்வொரு மாநிலத்திற்கும் ரீரைட்-ரூல் regex இல்லாத இருப்பிட வழிசெலுத்தல்](notes/location-routing-without-regex.md)**: ஒவ்வொரு பிராந்தியத்திற்கும் ஒரு ரீரைட் விதிக்குப் பதிலாக ஒவ்வொரு மாநிலம், நகரப் பக்கத்திற்கும் ஒரே வழிசெலுத்தல் பாதை.
- **[~20 செருகுநிரல்கள் ஒரு பராமரிப்புத்தன்மை பந்தயம், இலவசம் அல்ல](notes/plugin-per-source-tradeoff.md)**: தவறு தனிமைப்படுத்தலின் விலை என்பது எல்லாவற்றையும் ஒரே சீராக வைத்திருக்க அதிக பரப்பளவு.
