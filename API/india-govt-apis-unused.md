# India Government APIs Not Yet Used

Free government data sources that don't map to any category IndiaRealTime currently covers (see [india-free-apis.md](india-free-apis.md) for the ones already in use). Listed here as candidates for future plugins, not as a to-do commitment.

| Source | What it covers | Endpoint / access | Auth |
|---|---|---|---|
| data.gov.in OGD Platform (general catalog) | Thousands of datasets beyond the ones already used: census, education, health, transport, water resources, industry | [api.data.gov.in](https://data.gov.in/help/how-use-datasetapi) | Free API key (self-register) |
| APISetu (National API Exchange) | Directory of live APIs across ministries; a starting point for finding what's actually available before building against a dataset | [apisetu.gov.in](https://www.apisetu.gov.in/) | Varies by API, some free |
| CoWIN Public API | COVID vaccination center and session data by district or pincode | [apisetu.gov.in/public/marketplace/api/cowin/cowin-public-v2](https://apisetu.gov.in/public/marketplace/api/cowin/cowin-public-v2) | None for the public tier |
| NDAP (NITI Aayog) | Socio-economic indicators across sectors, standardized to one schema so datasets from different departments can be combined | [ndap.niti.gov.in](https://ndap.niti.gov.in/) | Free, registration for API access |
| Bhuvan (ISRO) | Satellite imagery and geospatial data: land cover, water resources, disaster maps | [bhuvan-app1.nrsc.gov.in/api](https://bhuvan-app1.nrsc.gov.in/api/) | Free registration for most layers |
| Census 2011 datasets | Population, literacy, and demographic data down to district level | search "census" on [data.gov.in](https://www.data.gov.in) | Free API key |
| NCRB crime data | State/district-level crime statistics, published annually | search "NCRB" on [data.gov.in](https://www.data.gov.in) | Free API key |
| Union Budget data | Ministry-wise budget allocation and expenditure, historical and current | search "union budget" on [data.gov.in](https://www.data.gov.in) | Free API key |

## Why these aren't in use

None of them fit the site's current categories (prices, environment, civic/time, culture, sport). Adding one means adding a category, not just a plugin, so this list is a reference for what's possible, not a queue.

Know a free India government API that's missing from this list? Open an issue or a PR against this file.
