## 📱 IndiaRealTime ਬਾਰੇ

### ਸਮੱਸਿਆ ਕੀ ਹੈ

ਡਾਟਾ ਪਹਿਲਾਂ ਤੋਂ ਹੀ ਮੌਜੂਦ ਹੈ ਅਤੇ ਜ਼ਿਆਦਾਤਰ ਜਨਤਕ ਹੈ। ਇਹ ਸਿਰਫ਼ ਦਰਜਨਾਂ ਵੱਖ-ਵੱਖ ਸਰਕਾਰੀ ਅਤੇ PSU ਪੋਰਟਲਾਂ ਵਿੱਚ ਖਿੱਲਰਿਆ ਹੋਇਆ ਹੈ, ਹਰ ਇੱਕ ਦਾ ਆਪਣਾ ਫਾਰਮੈਟ, ਅੱਪਡੇਟ ਹੋਣ ਦਾ ਸਮਾਂ, ਅਤੇ (ਅਕਸਰ) ਭਰੋਸੇਯੋਗਤਾ ਦੀਆਂ ਸਮੱਸਿਆਵਾਂ।

ਪੰਜਾਬ ਵਿੱਚ ਮੰਡੀ ਭਾਅ ਦੇਖਣ ਵਾਲੇ ਕਿਸਾਨ ਨੂੰ ਪਤਾ ਹੋਣਾ ਚਾਹੀਦਾ ਹੈ ਕਿ Agmarknet ਨਾਂ ਦੀ ਕੋਈ ਚੀਜ਼ ਮੌਜੂਦ ਹੈ। ਬਾਹਰ ਜਾਣਾ ਸੁਰੱਖਿਅਤ ਹੈ ਜਾਂ ਨਹੀਂ ਇਹ ਜਾਣਨ ਵਾਲੇ ਕਿਸੇ ਨੂੰ ਪਤਾ ਹੋਣਾ ਚਾਹੀਦਾ ਹੈ ਕਿ CPCB ਵੱਖਰੀ ਵੈੱਬਸਾਈਟ 'ਤੇ, ਵੱਖਰੇ ਫਾਰਮੈਟ ਵਿੱਚ AQI ਛਾਪਦਾ ਹੈ। ਬਾਲਣ ਦੀਆਂ ਕੀਮਤਾਂ ਰੋਜ਼ ਬਦਲਦੀਆਂ ਹਨ ਅਤੇ ਰਾਜ ਅਨੁਸਾਰ ਵੱਖਰੀਆਂ ਹੁੰਦੀਆਂ ਹਨ (ਵੱਖ-ਵੱਖ VAT ਦਰਾਂ), ਪਰ ਹਰ ਤੇਲ ਕੰਪਨੀ ਸਿਰਫ਼ ਆਪਣੇ ਅੰਕੜੇ, ਵੱਖਰੇ-ਵੱਖਰੇ, ਸਿਰਫ਼ ਉਨ੍ਹਾਂ ਸ਼ਹਿਰਾਂ ਲਈ ਛਾਪਦੀ ਹੈ ਜਿੱਥੇ ਉਹ ਸੇਵਾ ਦਿੰਦੀ ਹੈ।

ਇਸ ਲਈ ਨਵਾਂ ਡਾਟਾ ਇਕੱਠਾ ਕਰਨ ਦੀ ਲੋੜ ਨਹੀਂ। ਸਿਰਫ਼ ਕਿਸੇ ਨੂੰ ਜੋ ਪਹਿਲਾਂ ਤੋਂ ਜਨਤਕ ਹੈ ਉਸਨੂੰ ਲਿਆ ਕੇ, ਫਾਰਮੈਟ ਨੂੰ ਆਮ ਬਣਾ ਕੇ, ਮੰਡੀ ਭਾਅ, ਬਾਲਣ ਦੀਆਂ ਕੀਮਤਾਂ, AQI, ਮੌਸਮ ਚੇਤਾਵਨੀਆਂ ਆਦਿ ਨੂੰ ਇੱਕੋ ਥਾਂ ਰੱਖਣਾ ਹੈ ਤਾਂ ਜੋ ਕੋਈ ਵਿਅਕਤੀ ਪੰਜ ਵੱਖ-ਵੱਖ ਸਰਕਾਰੀ ਸਾਈਟਾਂ ਦੇ ਪੰਜ ਟੈਬ ਖੋਲ੍ਹਣ ਦੀ ਬਜਾਏ ਕੁਝ ਸਕਿੰਟਾਂ ਵਿੱਚ ਦੇਖ ਸਕੇ। **ਇਹੀ ਕਮੀ IndiaRealTime ਪੂਰੀ ਕਰਦਾ ਹੈ।**

### ਵਿਜ਼ਿਟਰਾਂ ਲਈ ਇਹ ਕਿਵੇਂ ਕੰਮ ਕਰਦਾ ਹੈ

- **ਥਾਂ ਅਨੁਸਾਰ ਬ੍ਰਾਊਜ਼ ਕਰੋ**: URL `/state/city/category/` ਪੈਟਰਨ ਦੀ ਪਾਲਣਾ ਕਰਦੇ ਹਨ (ਜਿਵੇਂ ਇੱਕ ਰਾਜ ਦਾ ਪੰਨਾ, ਫਿਰ ਸ਼ਹਿਰ ਵਿੱਚ ਜਾਣਾ, ਫਿਰ ਬਾਲਣ ਭਾਅ ਜਾਂ AQI ਵਰਗੀ ਕਿਸੇ ਖਾਸ ਸ਼੍ਰੇਣੀ ਵਿੱਚ)। ਜ਼ਿਆਦਾਤਰ ਸ਼੍ਰੇਣੀਆਂ ਰਾਸ਼ਟਰੀ ਸੰਖੇਪ ਜਾਣਕਾਰੀ ਅਤੇ ਸ਼ਹਿਰ-ਵਿਸ਼ੇਸ਼ ਵੇਰਵੇ ਪੰਨੇ ਦੋਵਾਂ ਰੂਪਾਂ ਵਿੱਚ ਮੌਜੂਦ ਹਨ।
- **ਭਾਅ ਦੀ ਤੁਲਨਾ ਕਰੋ**: ਇੱਕ ਪ੍ਰਾਈਸ-ਕੰਪੈਰਿਜ਼ਨ ਵਿਊ ਕਿਸੇ ਵਸਤੂ ਜਾਂ ਬਾਲਣ ਦੀ ਕਿਸਮ ਨੂੰ ਸ਼ਹਿਰਾਂ/ਰਾਜਾਂ ਵਿੱਚ ਨਾਲੋ-ਨਾਲ ਦਿਖਾਉਂਦਾ ਹੈ, ਹਰ ਸ਼ਹਿਰ ਦਾ ਪੰਨਾ ਵੱਖਰਾ ਖੋਲ੍ਹਣ ਦੀ ਬਜਾਏ।
- **ਕੈਲਕੁਲੇਟਰ**: ਇੱਕ ਮੈਟਲਸ ਕੈਲਕੁਲੇਟਰ ਸਿਰਫ਼ ਪ੍ਰਤੀ-ਗ੍ਰਾਮ ਅੰਕੜਾ ਦਿਖਾਉਣ ਦੀ ਬਜਾਏ ਲਾਈਵ ਸੋਨੇ/ਚਾਂਦੀ ਦੇ ਭਾਅ ਨੂੰ ਭਾਰ ਅਤੇ ਸ਼ੁੱਧਤਾ ਅਨੁਸਾਰ ਬਦਲਦਾ ਹੈ।
- **ਸ਼ੇਅਰ ਕਾਰਡ**: ਡਾਟਾ ਪੰਨੇ ਸੋਸ਼ਲ ਪਲੇਟਫਾਰਮਾਂ ਲਈ ਸਹੀ ਆਕਾਰ ਦਾ ਸਾਂਝਾ ਕਰਨ ਯੋਗ ਚਿੱਤਰ ਕਾਰਡ (ਭਾਅ, ਤਾਰੀਖ, ਸਰੋਤ) ਬਣਾਉਂਦੇ ਹਨ, ਤਾਂ ਜੋ ਸਕ੍ਰੀਨਸ਼ਾਟ ਤੋਂ ਬਿਨਾਂ ਹੀ ਕੋਈ ਤੱਥ ਸਾਂਝਾ ਕੀਤਾ ਜਾ ਸਕੇ।
- **ਲੇਖਕ ਹੱਬ**: ਹਰ ਲੇਖ ਇੱਕ ਅਸਲੀ ਲੇਖਕ ਨੂੰ, ਉਨ੍ਹਾਂ ਦੇ ਪ੍ਰੋਫਾਈਲ ਪੰਨੇ ਸਮੇਤ, ਸਿਹਰਾ ਦਿੱਤਾ ਜਾਂਦਾ ਹੈ, ਗੁਮਨਾਮ ਬਾਈਲਾਈਨ ਨਹੀਂ। `/authors/` ਸਭ ਨੂੰ ਸੂਚੀਬੱਧ ਕਰਦਾ ਹੈ, `/author/<name>/` ਉਨ੍ਹਾਂ ਦਾ ਪ੍ਰਕਾਸ਼ਿਤ ਕੰਮ ਦਿਖਾਉਂਦਾ ਹੈ।

## 🏗️ ਵੈੱਬ ਐਪਲੀਕੇਸ਼ਨ ਦਾ ਆਰਕੀਟੈਕਚਰ

ਭਾਰਤ ਵਿੱਚ ਜ਼ਿਆਦਾਤਰ "ਲਾਈਵ ਡਾਟਾ" ਸਾਈਟਾਂ ਜਾਂ ਤਾਂ ਦਿਨ ਵਿੱਚ ਇੱਕ ਵਾਰ ਸਕ੍ਰੈਪ ਕਰਕੇ ਇਸਨੂੰ ਰੀਅਲ-ਟਾਈਮ ਕਹਿੰਦੀਆਂ ਹਨ, ਜਾਂ ਇੱਕ ਪੇਜ-ਬਿਲਡਰ ਥੀਮ 'ਤੇ ਦਰਜਨਾਂ ਗੈਰ-ਸੰਬੰਧਿਤ ਵਿਜੇਟ ਜੋੜਦੀਆਂ ਰਹਿੰਦੀਆਂ ਹਨ ਜਦੋਂ ਤੱਕ ਇਹ ਸੰਭਾਲਣ ਯੋਗ ਨਹੀਂ ਰਹਿੰਦੀ। IndiaRealTime ਲਗਭਗ 15 ਵੱਖ-ਵੱਖ ਜਨਤਕ ਡਾਟਾ ਸਰੋਤਾਂ (ਸਰਕਾਰੀ API, ਐਕਸਚੇਂਜ, ਮੌਸਮ ਅਤੇ ਭੂਚਾਲ ਫੀਡ) ਤੋਂ ਡਾਟਾ ਲੈਂਦੀ ਹੈ ਅਤੇ ਹਰ ਇੱਕ ਨੂੰ ਇੱਕ ਮੋਨੋਲਿਥ ਦੀ ਬਜਾਏ ਆਪਣੀ ਛੋਟੀ, ਟੈਸਟ ਕਰਨ ਯੋਗ ਇਕਾਈ ਵਿੱਚ ਬਦਲ ਦਿੰਦੀ ਹੈ।

ਜੇ ਤੁਸੀਂ ਇੱਕ ਡਾਟਾ-ਐਗਰੀਗੇਸ਼ਨ ਸਾਈਟ, ਪਲੱਗਇਨ-ਆਧਾਰਿਤ ਆਰਕੀਟੈਕਚਰ, ਜਾਂ ਅਜਿਹਾ ਕੁਝ ਬਣਾ ਰਹੇ ਹੋ ਜਿੱਥੇ "ਅੱਪਸਟ੍ਰੀਮ API ਆਖਰਕਾਰ ਧੋਖਾ ਦੇਵੇਗੀ" ਇੱਕ ਅਸਲੀ ਡਿਜ਼ਾਈਨ ਪਾਬੰਦੀ ਹੈ, ਤਾਂ ਇਹ ਤੁਹਾਡੇ ਲਈ ਹੀ ਲਿਖਿਆ ਗਿਆ ਹੈ।

### ਤਕਨੀਕੀ ਡਾਇਗ੍ਰਾਮ

```
Public data sources (govt APIs, exchanges, weather/seismic feeds, ~15 total)
        │
        ▼
One WordPress plugin per source  ──►  WP-Cron fetch on its own schedule
  (fetch → validate → normalize)       (e.g. every 6h for commodities/AQI,
        │                               daily for fuel prices)
        ▼
WP transient cache (MySQL-backed)  ◄── on fetch failure, keep serving the
        │                               last good cached value instead of
        ▼                               erroring or showing nothing
Custom theme templates (PHP)
  render location/category pages
        │
        ▼
irt-dataset-schema → schema.org JSON-LD  +  irt-api-health-monitor watches
  (machine-readable structured data)       all fetchers from one dashboard
        │
        ▼
IndexNow ping on update → search engines re-crawl fresh data within minutes,
  not on their own schedule
```

### ਡਿਜ਼ਾਈਨ ਫ਼ਲਸਫ਼ਾ

**ਹਰ ਡਾਟਾ ਸਰੋਤ ਇੱਕ ਪੂਰੀ ਤਰ੍ਹਾਂ ਸੁਤੰਤਰ ਪਲੱਗਇਨ ਹੈ**, ਸਾਂਝੀ ਇੰਜੈਸ਼ਨ ਪਾਈਪਲਾਈਨ ਨਹੀਂ। ਇੱਕ ਪਲੱਗਇਨ ਦਾ ਆਪਣਾ ਫੈਚ ਸ਼ਡਿਊਲ, ਕੈਸ਼, ਅਤੇ ਅਸਫਲਤਾ ਸੰਭਾਲਣਾ ਹੁੰਦਾ ਹੈ। ਜੇ ਕੋਈ ਸਰਕਾਰੀ API ਆਪਣਾ ਜਵਾਬ ਫਾਰਮੈਟ ਬਦਲ ਦੇਵੇ ਜਾਂ ਬੰਦ ਹੋ ਜਾਵੇ, ਤਾਂ ਠੀਕ ਇੱਕ ਪਲੱਗਇਨ ਟੁੱਟਦਾ ਹੈ। ਬਾਕੀ ~19 ਸੇਵਾ ਦਿੰਦੇ ਰਹਿੰਦੇ ਹਨ। `irt-api-health-monitor` ਇਸ ਲਈ ਹੈ ਕਿਉਂਕਿ ਇੰਨੇ ਸਾਰੇ ਸੁਤੰਤਰ ਹਿੱਲਦੇ ਹਿੱਸਿਆਂ ਨਾਲ, ਹਰ ਪਲੱਗਇਨ ਦੇ ਲੌਗ ਹੱਥੀਂ ਦੇਖਣ ਦੀ ਬਜਾਏ ਇੱਕ ਜਗ੍ਹਾ ਤੋਂ ਸਭ ਨੂੰ ਦੇਖਣ ਵਾਲਾ ਸਿਸਟਮ ਚਾਹੀਦਾ ਹੈ।

### ਸਟੈਕ

- **WordPress** (ਕਸਟਮ ਥੀਮ, ਕੋਈ ਪੇਜ ਬਿਲਡਰ ਨਹੀਂ): PHP ਟੈਂਪਲੇਟ, ਵਨੀਲਾ JS/CSS
- **~20 ਕਸਟਮ ਪਲੱਗਇਨ**, ਹਰ ਡਾਟਾ ਸਰੋਤ ਲਈ ਇੱਕ, ਹਰ ਇੱਕ ਦੀ ਆਪਣੀ ਫੈਚ/ਕੈਸ਼ ਲੇਅਰ
- ਸਟੋਰੇਜ ਅਤੇ ਟ੍ਰਾਂਜ਼ੀਐਂਟ ਕੈਸ਼ਿੰਗ ਲਈ **MySQL**; ਲੋਕਲ ਡੇਵ ਲਈ Docker Compose
- ਇੱਕ ਸਮਰਪਿਤ ਪਲੱਗਇਨ (`irt-dataset-schema`) ਰਾਹੀਂ Schema.org ਸਟ੍ਰਕਚਰਡ ਡਾਟਾ
- ਡਾਟਾ ਅੱਪਡੇਟ 'ਤੇ ਲਗਭਗ ਤੁਰੰਤ ਸਰਚ ਇੰਜਣ ਇੰਡੈਕਸਿੰਗ ਲਈ IndexNow ਇੰਟੀਗ੍ਰੇਸ਼ਨ

### ਅਸਲੀ ਏਕੀਕਰਨ ਉਦਾਹਰਣਾਂ

#### ਉਦਾਹਰਣ 1: ਮੰਡੀ ਭਾਅ ਦੇਖਦਾ ਕਿਸਾਨ (CLI)
```bash
# Get wheat prices in Punjab
$ indiarealtime mandi --commodity wheat --state Punjab

Commodity  Market           State         City      Price (₹)  Unit
wheat      APMC Ludhiana    Punjab        Ludhiana  2450       Quintal
wheat      APMC Amritsar    Punjab        Amritsar  2420       Quintal
```

#### ਉਦਾਹਰਣ 2: ਪ੍ਰਾਈਸ ਅਲਰਟ ਬੌਟ ਬਣਾਉਂਦਾ ਸਟਾਰਟਅੱਪ (Python)
```python
from indiarealtime import IndiaRealTime

irt = IndiaRealTime()

# Get current wheat prices
prices = irt.mandi_prices(commodity="wheat", state="Punjab", limit=5)

for price in prices:
    print(f"📊 {price.market}: ₹{price.price}/{price.unit}")
    
    # Alert if price drops below ₹2400
    if price.price < 2400:
        send_sms_alert(f"Wheat at {price.market} is ₹{price.price}!")
```

#### ਉਦਾਹਰਣ 3: ਬਾਲਣ ਭਾਅ ਚੈੱਕ ਕਰਦੀ ਡਿਲੀਵਰੀ ਐਪ (REST API)
```javascript
// Fetch fuel prices for driver earnings calculation
fetch('http://localhost:5000/v1/fuel/prices?state=Maharashtra&type=diesel')
  .then(r => r.json())
  .then(data => {
    data.results.forEach(price => {
      console.log(`Diesel in ${price.city}: ₹${price.price}/L`);
    });
  });
```

#### ਉਦਾਹਰਣ 4: AQI ਸਕ੍ਰੈਪ ਕਰਦੀ ਨਿਊਜ਼ ਵੈੱਬਸਾਈਟ (Python)
```python
from indiarealtime import IndiaRealTime
import requests

irt = IndiaRealTime()
aqi = irt.air_quality(city="Delhi")

if aqi[0].aqi > 300:
    # Post alert headline
    headline = f"🚨 Air Quality SEVERE in {aqi[0].city}: AQI {aqi[0].aqi}"
    post_to_website(headline)
```

#### ਉਦਾਹਰਣ 5: ਦਰਾਂ ਦਿਖਾਉਂਦਾ ਫਾਈਨਾਂਸ ਡੈਸ਼ਬੋਰਡ (React)
```jsx
import { useState, useEffect } from 'react';

function CurrencyRates() {
  const [rates, setRates] = useState({});
  
  useEffect(() => {
    fetch('/api/v1/finance/currency?base=INR&symbols=USD,EUR,GBP')
      .then(r => r.json())
      .then(d => setRates(d.rates));
  }, []);
  
  return (
    <div>
      <h2>INR Exchange Rates</h2>
      <p>1 INR = ${rates.USD?.toFixed(4)} USD</p>
      <p>1 INR = €{rates.EUR?.toFixed(4)} EUR</p>
    </div>
  );
}
```

## ⚠️ ਤਕਨੀਕੀ ਚੁਣੌਤੀਆਂ

### ਇੰਜਨੀਅਰਿੰਗ ਫੈਸਲੇ ਅਤੇ ਸਬਕ

ਇਨ੍ਹਾਂ ਵਿੱਚੋਂ ਹਰ ਚੁਣੌਤੀ ਇੰਨੀ ਲੰਬੀ ਹੋ ਗਈ ਕਿ ਇਸਨੂੰ ਆਪਣਾ ਪੰਨਾ ਬਣਾਉਣਾ ਪਿਆ:

- **[ਜਾਣਬੁੱਝ ਕੇ ਪੁਰਾਣਾ ਡਾਟਾ ਦੇਣਾ](notes/stale-cache-fallback.md)**: ਸਰਕਾਰੀ ਅਤੇ ਐਕਸਚੇਂਜ API ਭਰੋਸੇਯੋਗ ਨਹੀਂ ਹੁੰਦੀਆਂ, ਫਿਰ ਵੀ ਸਾਈਟ ਨੂੰ ਭਰੋਸੇਯੋਗ ਦਿਖਣਾ ਪੈਂਦਾ ਹੈ। ਜਦੋਂ ਕੋਈ ਅੱਪਸਟ੍ਰੀਮ API ਅਸਫਲ ਹੁੰਦੀ ਹੈ, ਅਸੀਂ ਗਲਤੀ ਦੇਣ ਜਾਂ ਕੁਝ ਨਾ ਦਿਖਾਉਣ ਦੀ ਬਜਾਏ ਆਖਰੀ ਵਧੀਆ ਕੈਸ਼ ਕੀਤਾ ਮੁੱਲ ਦਿਖਾਉਂਦੇ ਹਾਂ।
- **[ਪਹੁੰਚਯੋਗਤਾ ਅਤੇ ਰੰਗ, ਦੋਵੇਂ ਜ਼ਰੂਰੀ](notes/cvd-safe-aqi-colors.md)**: ਡਾਟਾ ਸਭ ਲਈ ਪਹੁੰਚਯੋਗ ਹੋਵੇ, ਇਸ ਲਈ ਹਰ ਅਰਥਪੂਰਨ ਰੰਗ ਨੂੰ WCAG ਕੰਟ੍ਰਾਸਟ ਅਤੇ ਕਲਰ-ਵਿਜ਼ਨ-ਡੈਫੀਸ਼ੈਂਸੀ ਸਿਮੂਲੇਸ਼ਨ ਦੇ ਖਿਲਾਫ ਪਰਖਿਆ ਜਾਂਦਾ ਹੈ।
- **[ਦੋ ਭਾਸ਼ਾਵਾਂ ਵਿੱਚ ਇੱਕੋ ਜਿਹਾ ਹੈਸ਼ ਬਣਾਉਣਾ](notes/cross-language-hash-parity.md)**: PHP ਅਤੇ JavaScript ਇੰਟੀਜਰ ਓਵਰਫਲੋ 'ਤੇ ਸਹਿਮਤ ਨਹੀਂ ਹੁੰਦੇ, ਫਿਰ ਵੀ ਲੇਖਕ ਪਛਾਣ ਉਨ੍ਹਾਂ ਦੇ ਸਹਿਮਤ ਰਹਿਣ 'ਤੇ ਹੀ ਨਿਰਭਰ ਹੈ।
- **[ਹਰ ਰਾਜ ਲਈ ਰੀਰਾਈਟ-ਰੂਲ regex ਤੋਂ ਬਿਨਾਂ ਲੋਕੇਸ਼ਨ ਰਾਊਟਿੰਗ](notes/location-routing-without-regex.md)**: ਹਰ ਖੇਤਰ ਲਈ ਇੱਕ ਰੀਰਾਈਟ ਰੂਲ ਬਣਾਉਣ ਦੀ ਬਜਾਏ ਹਰ ਰਾਜ ਅਤੇ ਸ਼ਹਿਰ ਦੇ ਪੰਨੇ ਲਈ ਇੱਕੋ ਰਾਊਟਿੰਗ ਰਸਤਾ।
- **[~20 ਪਲੱਗਇਨ ਇੱਕ ਸਾਂਭ-ਸੰਭਾਲ ਦਾਅ ਹੈ, ਮੁਫਤ ਦੀ ਚੀਜ਼ ਨਹੀਂ](notes/plugin-per-source-tradeoff.md)**: ਫਾਲਟ ਆਈਸੋਲੇਸ਼ਨ ਦੀ ਕੀਮਤ ਦਾ ਮਤਲਬ ਹੈ ਸਭ ਕੁਝ ਇੱਕਸਾਰ ਰੱਖਣ ਲਈ ਵੱਧ ਖੇਤਰ।
