## 📱 IndiaRealTime विषये

### समस्या का

दत्तांशः पूर्वमेव विद्यते, प्रायः सार्वजनिकश्च अस्ति। सः केवलं बहुषु भिन्न-सरकारी-PSU-द्वारेषु विकीर्णः वर्तते, प्रत्येकस्य स्वकीयं रूपम्, अद्यतन-समयः, तथा (बहुधा) विश्वसनीयता-समस्याः च सन्ति।

पञ्जाबे मण्डी-मूल्यं द्रष्टुम् इच्छुकेन कृषकेण ज्ञातव्यं यत् Agmarknet नाम किमपि विद्यते इति। बहिः गमनं सुरक्षितं वा न वा इति ज्ञातुम् इच्छुकेन जनेन ज्ञातव्यं यत् CPCB भिन्नस्यां वेबसाइट्याम्, भिन्नरूपेण च AQI प्रकाशयति। इन्धन-मूल्यानि प्रतिदिनं परिवर्तन्ते, राज्यानुसारं च भिन्नानि भवन्ति (भिन्नाः VAT-दराः), परन्तु प्रत्येकं तैल-कम्पनी स्वकीयान् संख्याङ्कान् मात्रं, पृथक् पृथक्, केवलं यत्र सेवां ददाति तेषु नगरेषु एव प्रकाशयति।

अस्य कृते नूतन-दत्तांशस्य सङ्ग्रहणं न आवश्यकम्। केवलं पूर्वमेव सार्वजनिकं यत् तत् आनीय, रूपाणि सामान्यीकृत्य, मण्डी-मूल्यानि, इन्धन-मूल्यानि, AQI, मौसम-चेतावनीः इत्यादीनि एकस्मिन् स्थाने स्थापयितव्यानि, येन जनः पञ्चानां भिन्न-सरकारी-स्थलानां पञ्च-वातायनानि उद्घाट्य तत्स्थाने क्षणेषु एव द्रष्टुं शक्नुयात्। **इमम् एव अभावं IndiaRealTime पूरयति।**

| वर्गः | उदाहरणानि |

| पर्यावरणम् | वायुगुणवत्ता (AQI, CPCB-पट्टिकाः), मौसम-चेतावन्यः, भूकम्प-चेतावन्यः |
| नागरिक-/समय-सम्बद्धम् | बैंक्-अवकाशाः, पिन्कोड्-अन्वेषणम्, समयक्षेत्र-परिवर्तनम् |

| क्रीडा | सजीव-क्रिकेट्-गुणाङ्काः |

मूल-दत्तांशः यत्र अनुमन्यते तत्र व्याप्तिः नगर-/राज्य-स्तरे सूक्ष्मा भवति। यथा, इन्धन-मूल्यानि राष्ट्रिय-सरासरी न, अपितु प्रतिनगरम् अनुसृतानि भवन्ति।

अस्य पृष्ठतः स्थितानां निःशुल्क-भारतीय-दत्तांश-API-नां सम्पूर्णा सूची, स्थलं यानि अद्यापि न उपयुङ्क्ते तानि सरकारी-API-नि अपि सह, [API/](API/) इत्यत्र वर्तते।

### दर्शकानां कृते इदं कथं कार्यं करोति

- **स्थानानुसारं भ्रमत**: URL-नि `/state/city/category/` इति क्रमम् अनुसरन्ति (यथा राज्य-पृष्ठम्, ततः नगरं प्रति, ततः इन्धन-मूल्यानि अथवा AQI इव विशिष्ट-वर्गं प्रति)। बहवः वर्गाः राष्ट्रिय-अवलोकनरूपेण नगर-विशिष्ट-विवरण-पृष्ठरूपेण च द्वयोः रूपयोः वर्तन्ते।
- **मूल्यानि तुलयत**: मूल्य-तुलना-दृश्यं वस्तु अथवा इन्धन-प्रकारं नगरेषु/राज्येषु समानान्तरं दर्शयति, प्रतिनगर-पृष्ठं पृथक् उद्घाटनस्य स्थाने।
- **गणकाः**: धातु-गणकः प्रति-ग्राम-संख्यां मात्रं दर्शयितुं स्थाने सजीव-सुवर्ण-/रजत-दराः भारशुद्धत्वानुसारं परिवर्तयति।
- **साझाकरण-पत्राणि**: दत्तांश-पृष्ठानि सामाजिक-मञ्चानां कृते योग्य-परिमाणस्य साझाकरणीय-चित्र-पत्रं (मूल्यम्, दिनाङ्कः, स्रोतः) निर्मान्ति, येन चित्रपट-रहितम् अपि तथ्यं साझां कर्तुं शक्यते।
- **लेखक-केन्द्रम्**: प्रत्येकः लेखः सत्य-लेखकाय, तस्य विवरण-पृष्ठेन सह, श्रेयः दीयते, न तु अज्ञात-नामेन। `/authors/` सर्वान् सूचीकरोति, `/author/<name>/` तेषां प्रकाशित-कार्यं दर्शयति।

## 🏗️ वेब-अनुप्रयोगस्य वास्तुकला

भारते बहवः "सजीव-दत्तांश" स्थलानि वा दिने एकवारं सङ्गृह्य तत् सजीव-कालम् इति वदन्ति, वा एकस्मिन् पृष्ठ-निर्माता-रूपे दर्जन-सङ्ख्यकानि असम्बद्ध-विजेट्-यन्त्राणि योजयन्ति यावत् तत् सम्भालयितुं न शक्यते। IndiaRealTime प्रायः पञ्चदशभ्यः भिन्न-सार्वजनिक-दत्तांश-स्रोतेभ्यः (सरकारी-API, विनिमय-स्थानानि, मौसम-भूकम्प-प्रवाहाः) दत्तांशं गृह्णाति, प्रत्येकं च एकस्य महाकाय-रचनायाः स्थाने स्वकीयां लघु-परीक्षणीय-एककं परिवर्तयति।

यदि भवान् दत्तांश-सङ्ग्रहण-स्थलम्, प्लगइन्-आधारित-वास्तुकलां, वा तादृशं किमपि निर्मीयते यत्र "उपरिस्थ-API अन्ततः वञ्चयिष्यति" इति सत्य-रचना-सीमा भवति, तर्हि इदं भवत एव लिखितम्।

### तकनीकी-रेखाचित्रम्

```
Public data sources (govt APIs, exchanges, weather/seismic feeds, ~15 total)
        │
        ▼
One WordPress plugin per source  ──►  WP-Cron fetch on its own schedule
  (fetch → validate → normalize)       (e.g. every 6h for commodities/AQI,
        │                               daily for fuel prices)
        ▼
WP transient cache (MySQL-backed)  ◄── on fetch failure, keep serving the
        │                               last good cached value instead of
        ▼                               erroring or showing nothing
Custom theme templates (PHP)
  render location/category pages
        │
        ▼
irt-dataset-schema → schema.org JSON-LD  +  irt-api-health-monitor watches
  (machine-readable structured data)       all fetchers from one dashboard
        │
        ▼
IndexNow ping on update → search engines re-crawl fresh data within minutes,
  not on their own schedule
```

### रचना-दर्शनम्

**प्रत्येकं दत्तांश-स्रोतः पूर्णतया स्वतन्त्रः प्लगइन् अस्ति**, न तु साझा-ग्रहण-मार्गः। एकस्य प्लगइनस्य स्वकीयः आहरण-कालक्रमः, संचयः, विफलता-व्यवस्थापनं च भवति। यदि कापि सरकारी-API स्वस्य प्रतिक्रिया-रूपं परिवर्तयति वा निष्क्रिया भवति, तर्हि ठीक् एकः एव प्लगइन् भज्यते। शेषाः ~१९ सेवां दातुं निरन्तरं प्रयतन्ते। एतावत्सु स्वतन्त्र-चलमान-अंशेषु सत्सु, प्रत्येकस्य प्लगइनस्य लेखान् हस्तेन परीक्षितुं स्थाने सर्वान् एकस्मात् स्थलात् निरीक्षमाणा व्यवस्था आवश्यकी इति कारणात् `irt-api-health-monitor` विद्यते।

### तकनीकी-स्तरः

- **WordPress** (स्वनिर्मित-रूपम्, न पृष्ठ-निर्मापकः): PHP-प्रतिरूपाणि, वेनिला JS/CSS
- **~२० स्वनिर्मित-प्लगइन्स्**, प्रति-दत्तांश-स्रोतम् एकम्, प्रत्येकस्य स्वकीयः आहरण-/संचय-स्तरः
- संचयनाय क्षणिक-संचयनाय च **MySQL**; स्थानीय-विकासाय Docker Compose
- एकेन समर्पित-प्लगइनेन (`irt-dataset-schema`) माध्यमेन Schema.org रचित-दत्तांशः
- दत्तांश-अद्यतनेषु प्रायः तत्क्षण-अन्वेषण-यन्त्र-सूचीकरणाय IndexNow एकीकरणम्

### वास्तविक-एकीकरण-उदाहरणानि

#### उदाहरणम् १: मण्डी-मूल्यं पश्यन् कृषकः (CLI)
```bash
# Get wheat prices in Punjab
$ indiarealtime mandi --commodity wheat --state Punjab

Commodity  Market           State         City      Price (₹)  Unit
wheat      APMC Ludhiana    Punjab        Ludhiana  2450       Quintal
wheat      APMC Amritsar    Punjab        Amritsar  2420       Quintal
```

#### उदाहरणम् २: मूल्य-चेतावनी-यन्त्रं निर्मान् नव-उद्यमः (Python)
```python
from indiarealtime import IndiaRealTime

irt = IndiaRealTime()

# Get current wheat prices
prices = irt.mandi_prices(commodity="wheat", state="Punjab", limit=5)

for price in prices:
    print(f"📊 {price.market}: ₹{price.price}/{price.unit}")
    
    # Alert if price drops below ₹2400
    if price.price < 2400:
        send_sms_alert(f"Wheat at {price.market} is ₹{price.price}!")
```

#### उदाहरणम् ३: इन्धन-मूल्यं परीक्षमाणा वितरण-अनुप्रयोगः (REST API)
```javascript
// Fetch fuel prices for driver earnings calculation
fetch('http://localhost:5000/v1/fuel/prices?state=Maharashtra&type=diesel')
  .then(r => r.json())
  .then(data => {
    data.results.forEach(price => {
      console.log(`Diesel in ${price.city}: ₹${price.price}/L`);
    });
  });
```

#### उदाहरणम् ४: AQI सङ्गृह्णाती वार्ता-वेबसाइट् (Python)
```python
from indiarealtime import IndiaRealTime
import requests

irt = IndiaRealTime()
aqi = irt.air_quality(city="Delhi")

if aqi[0].aqi > 300:
    # Post alert headline
    headline = f"🚨 Air Quality SEVERE in {aqi[0].city}: AQI {aqi[0].aqi}"
    post_to_website(headline)
```

#### उदाहरणम् ५: दराः दर्शयत् वित्त-फलकम् (React)
```jsx
import { useState, useEffect } from 'react';

function CurrencyRates() {
  const [rates, setRates] = useState({});
  
  useEffect(() => {
    fetch('/api/v1/finance/currency?base=INR&symbols=USD,EUR,GBP')
      .then(r => r.json())
      .then(d => setRates(d.rates));
  }, []);
  
  return (
    <div>
      <h2>INR Exchange Rates</h2>
      <p>1 INR = ${rates.USD?.toFixed(4)} USD</p>
      <p>1 INR = €{rates.EUR?.toFixed(4)} EUR</p>
    </div>
  );
}
```

```bash
docker-compose up

# WordPress at http://localhost:8080
# API Server at http://localhost:5000
# Monitoring at http://localhost:3000
```

### स्वयं प्रयतस्व

`scripts/fetch-pincode.js` इति स्थलस्य प्लगइन्-यन्त्राणि यत् आहरण-सामान्यीकरण-क्रमम् उपयुञ्जते तस्य लघु-स्वतन्त्र-उदाहरणम्, उपरि-सूच्याः कुञ्चिका-रहितेन एकेन API उपरि प्रयुक्तम्:

```
node scripts/fetch-pincode.js 560001
```

## ⚠️ तकनीकी-आव्हानानि

### अभियान्त्रिकी-निर्णयाः पाठाश्च

एतेषु आव्हानेषु प्रत्येकम् एतावत् दीर्घं जातम् यत् तस्य स्वकीयं पृष्ठम् आवश्यकम् अभवत्:

- **[जानपूर्वकं पुरातन-दत्तांशं दानम्](notes/stale-cache-fallback.md)**: सरकारी-विनिमय-API विश्वसनीयाः न भवन्ति, तथापि स्थलेन विश्वसनीयवत् दृश्यं भवितव्यम्। यदा उपरिस्थ-API विफला भवति, तदा वयं त्रुटिं दातुं वा किमपि न दर्शयितुं स्थाने अन्तिमं शुभं संचित-मूल्यं दर्शयामः।
- **[सुगम्यता वर्णं च, द्वयम् अपि महत्त्वपूर्णम्](notes/cvd-safe-aqi-colors.md)**: दत्तांशः सर्वेभ्यः सुगम्यः भवेत् इति कृते प्रत्येकः अर्थपूर्णः वर्णः WCAG-वैषम्यस्य वर्ण-दृष्टि-न्यूनता-अनुकरणस्य च विरुद्धं परीक्ष्यते।
- **[द्वयोः भाषयोः समानं जनक-सङ्ख्या (hash)](notes/cross-language-hash-parity.md)**: PHP JavaScript च पूर्णाङ्क-अतिप्रवाहे न सहमते, तथापि लेखक-श्रेय-निर्धारणं तयोः सहमतेः एव अवलम्बते।
- **[प्रति-राज्यं पुनर्लेखन-नियम-regex विना स्थान-मार्गीकरणम्](notes/location-routing-without-regex.md)**: प्रति-क्षेत्रम् एकस्य पुनर्लेखन-नियमस्य स्थाने प्रति-राज्य-नगर-पृष्ठं कृते एकः एव मार्गः।
- **[~२० प्लगइन्स् एकः सम्भालन-दावः, न तु निःशुल्क-भोजनम्](notes/plugin-per-source-tradeoff.md)**: दोष-पृथक्करणस्य मूल्यम् इत्यर्थः सर्वं सुसङ्गतं स्थापयितुं अधिक-क्षेत्रफलम् आवश्यकम्।
