## 📱 IndiaRealTime-നെ കുറിച്ച്

### പ്രശ്നം എന്താണ്

ഡാറ്റ ഇതിനകം നിലവിലുണ്ട്, മിക്കതും പൊതുവായതാണ്. അത് ഡസൻ കണക്കിന് വ്യത്യസ്ത സർക്കാർ, PSU പോർട്ടലുകളിൽ ചിതറിക്കിടക്കുന്നു, ഓരോന്നിനും അതിന്റേതായ ഫോർമാറ്റ്, അപ്‌ഡേറ്റ് ഷെഡ്യൂൾ, (പലപ്പോഴും) വിശ്വാസ്യതാ പ്രശ്നങ്ങൾ.

പഞ്ചാബിലെ മണ്ടി വിലകൾ പരിശോധിക്കുന്ന ഒരു കർഷകൻ Agmarknet എന്നൊന്ന് ഉണ്ടെന്ന് അറിഞ്ഞിരിക്കണം. പുറത്തിറങ്ങുന്നത് സുരക്ഷിതമാണോ എന്ന് അറിയാൻ ആഗ്രഹിക്കുന്ന ആർക്കും CPCB വേറൊരു വെബ്‌സൈറ്റിൽ, വേറൊരു ഫോർമാറ്റിൽ AQI പ്രസിദ്ധീകരിക്കുന്നു എന്ന് അറിഞ്ഞിരിക്കണം. ഇന്ധന വിലകൾ ദിവസവും മാറുന്നു, സംസ്ഥാനം തോറും വ്യത്യാസപ്പെടുന്നു (വ്യത്യസ്ത VAT നിരക്കുകൾ), പക്ഷേ ഓരോ ഓയിൽ കമ്പനിയും തങ്ങൾ സേവനം നൽകുന്ന നഗരങ്ങൾക്ക് മാത്രം, വെവ്വേറെയായി, സ്വന്തം കണക്കുകൾ മാത്രം പ്രസിദ്ധീകരിക്കുന്നു.

ഇതിന് പുതിയ ഡാറ്റ ശേഖരിക്കേണ്ട ആവശ്യമില്ല. ഇതിനകം പൊതുവായുള്ളത് കൊണ്ടുവന്ന്, ഫോർമാറ്റുകൾ ഏകീകരിച്ച്, മണ്ടി വിലകൾ, ഇന്ധന വിലകൾ, AQI, കാലാവസ്ഥാ മുന്നറിയിപ്പുകൾ തുടങ്ങിയവ ഒരിടത്ത് വയ്ക്കുകയാണ് വേണ്ടത്, അങ്ങനെ ഒരാൾക്ക് അഞ്ച് വ്യത്യസ്ത സർക്കാർ സൈറ്റുകളുടെ അഞ്ച് ടാബുകൾ തുറക്കുന്നതിന് പകരം സെക്കൻഡുകൾക്കുള്ളിൽ പരിശോധിക്കാം. **ഈ വിടവാണ് IndiaRealTime നികത്തുന്നത്.**

### ഞങ്ങൾ എന്താണ് ട്രാക്ക് ചെയ്യുന്നത്

| വിഭാഗം | ഉദാഹരണങ്ങൾ |

| വിലകൾ | മണ്ടി (കാർഷിക ഉൽപ്പന്നം), ഇന്ധനം & LPG സംസ്ഥാനം/നഗരം അനുസരിച്ച്, വിലയേറിയ ലോഹങ്ങൾ, കറൻസി മാറ്റം, മ്യൂച്വൽ ഫണ്ട് NAV-കൾ, FD നിരക്കുകൾ, ടോൾ നിരക്കുകൾ |

| സ്പോർട്സ് | തത്സമയ ക്രിക്കറ്റ് സ്കോറുകൾ |

അടിസ്ഥാന ഡാറ്റ അനുവദിക്കുന്നിടത്ത് കവറേജ് നഗരം/സംസ്ഥാന തലത്തിൽ വിശദമാണ്. ഉദാഹരണത്തിന്, ഇന്ധന വിലകൾ ദേശീയ ശരാശരിയല്ല, ഓരോ നഗരവും അനുസരിച്ചാണ് ട്രാക്ക് ചെയ്യുന്നത്.

ഇതിന് പിന്നിലെ സൗജന്യ ഇന്ത്യൻ ഡാറ്റ API-കളുടെ പൂർണ്ണ ലിസ്റ്റ്, സൈറ്റ് ഇതുവരെ ഉപയോഗിക്കാത്ത സർക്കാർ API-കൾ ഉൾപ്പെടെ, [API/](API/)-ൽ ഉണ്ട്.

### സന്ദർശകർക്ക് ഇത് എങ്ങനെ പ്രവർത്തിക്കുന്നു

- **സ്ഥലം അനുസരിച്ച് ബ്രൗസ് ചെയ്യുക**: URL-കൾ `/state/city/category/` പാറ്റേൺ പിന്തുടരുന്നു (ഉദാ. ഒരു സംസ്ഥാന പേജ്, പിന്നീട് ഒരു നഗരത്തിലേക്ക്, പിന്നീട് ഇന്ധന വിലകൾ അല്ലെങ്കിൽ AQI പോലുള്ള ഒരു നിർദ്ദിഷ്ട വിഭാഗത്തിലേക്ക്). മിക്ക വിഭാഗങ്ങളും ദേശീയ അവലോകനമായും നഗര-നിർദ്ദിഷ്ട വിശദാംശ പേജായും രണ്ട് രൂപത്തിലും നിലവിലുണ്ട്.
- **വിലകൾ താരതമ്യം ചെയ്യുക**: ഓരോ നഗര പേജും വെവ്വേറെ തുറക്കുന്നതിന് പകരം, ഒരു വില-താരതമ്യ വ്യൂ ഒരു ഉൽപ്പന്നം അല്ലെങ്കിൽ ഇന്ധന തരം നഗരങ്ങളിലും സംസ്ഥാനങ്ങളിലും ഒരുമിച്ച് കാണിക്കുന്നു.
- **കാൽക്കുലേറ്ററുകൾ**: ഒരു ഗ്രാം വില മാത്രം കാണിക്കുന്നതിന് പകരം, ഒരു മെറ്റൽസ് കാൽക്കുലേറ്റർ തത്സമയ സ്വർണ്ണം/വെള്ളി നിരക്കുകൾ ഭാരവും പരിശുദ്ധിയും അനുസരിച്ച് മാറ്റുന്നു.
- **ഷെയർ കാർഡുകൾ**: ഡാറ്റ പേജുകൾ സോഷ്യൽ പ്ലാറ്റ്‌ഫോമുകൾക്ക് അനുയോജ്യമായ വലുപ്പത്തിലുള്ള ഷെയർ ചെയ്യാവുന്ന ഇമേജ് കാർഡ് (വില, തീയതി, സ്രോതസ്സ്) സൃഷ്ടിക്കുന്നു, അതിനാൽ സ്ക്രീൻഷോട്ട് ഇല്ലാതെ തന്നെ ഒരു വസ്തുത പങ്കിടാം.
- **രചയിതാക്കളുടെ ഹബ്**: ഓരോ ലേഖനവും അജ്ഞാത ബൈലൈൻ അല്ല, മറിച്ച് ഒരു യഥാർത്ഥ രചയിതാവിന്, അവരുടെ പ്രൊഫൈൽ പേജ് സഹിതം, ക്രെഡിറ്റ് ചെയ്യപ്പെടുന്നു. `/authors/` എല്ലാവരെയും ലിസ്റ്റ് ചെയ്യുന്നു, `/author/<name>/` അവരുടെ പ്രസിദ്ധീകരിച്ച സൃഷ്ടികൾ കാണിക്കുന്നു.

## 🏗️ വെബ് ആപ്ലിക്കേഷന്റെ ആർക്കിടെക്ചർ

ഇന്ത്യയിലെ മിക്ക "ലൈവ് ഡാറ്റ" സൈറ്റുകളും ഒന്നുകിൽ ദിവസത്തിൽ ഒരിക്കൽ സ്ക്രാപ്പ് ചെയ്ത് അതിനെ റിയൽ-ടൈം എന്ന് വിളിക്കുന്നു, അല്ലെങ്കിൽ അത് പരിപാലിക്കാൻ കഴിയാതാകുന്നത് വരെ ഒരു പേജ്-ബിൽഡർ തീമിൽ ഡസൻ കണക്കിന് ബന്ധമില്ലാത്ത വിജറ്റുകൾ കൂട്ടിച്ചേർക്കുന്നു. IndiaRealTime ഏകദേശം 15 വ്യത്യസ്ത പൊതു ഡാറ്റാ സ്രോതസ്സുകളിൽ (സർക്കാർ API-കൾ, എക്സ്ചേഞ്ചുകൾ, കാലാവസ്ഥാ, ഭൂകമ്പ ഫീഡുകൾ) നിന്ന് ഡാറ്റ എടുത്ത് ഓരോന്നിനെയും ഒരു മോണോലിത്തിന് പകരം അതിന്റേതായ ചെറിയ, പരീക്ഷിക്കാവുന്ന യൂണിറ്റാക്കി മാറ്റുന്നു.

നിങ്ങൾ ഒരു ഡാറ്റ-അഗ്രിഗേഷൻ സൈറ്റ്, പ്ലഗിൻ-അധിഷ്ഠിത ആർക്കിടെക്ചർ, അല്ലെങ്കിൽ "അപ്‌സ്ട്രീം API ഒടുവിൽ നിങ്ങളെ വഞ്ചിക്കും" എന്നത് ഒരു യഥാർത്ഥ ഡിസൈൻ പരിമിതിയായ എന്തെങ്കിലും നിർമ്മിക്കുകയാണെങ്കിൽ, ഇത് നിങ്ങൾക്ക് വേണ്ടിയാണ് എഴുതിയത്.

### സാങ്കേതിക രേഖാചിത്രം

```
Public data sources (govt APIs, exchanges, weather/seismic feeds, ~15 total)
        │
        ▼
One WordPress plugin per source  ──►  WP-Cron fetch on its own schedule
  (fetch → validate → normalize)       (e.g. every 6h for commodities/AQI,
        │                               daily for fuel prices)
        ▼
WP transient cache (MySQL-backed)  ◄── on fetch failure, keep serving the
        │                               last good cached value instead of
        ▼                               erroring or showing nothing
Custom theme templates (PHP)
  render location/category pages
        │
        ▼
irt-dataset-schema → schema.org JSON-LD  +  irt-api-health-monitor watches
  (machine-readable structured data)       all fetchers from one dashboard
        │
        ▼
IndexNow ping on update → search engines re-crawl fresh data within minutes,
  not on their own schedule
```

### ഡിസൈൻ തത്വശാസ്ത്രം

**ഓരോ ഡാറ്റാ സ്രോതസ്സും ഒരു പൂർണ്ണ സ്വതന്ത്ര പ്ലഗിനാണ്**, പങ്കിട്ട ഇൻജെഷൻ പൈപ്പ്‌ലൈൻ അല്ല. ഒരു പ്ലഗിന് അതിന്റേതായ ഫെച്ച് ഷെഡ്യൂൾ, കാഷ്, പരാജയ കൈകാര്യം ചെയ്യൽ ഉണ്ട്. ഏതെങ്കിലും സർക്കാർ API അതിന്റെ പ്രതികരണ ഫോർമാറ്റ് മാറ്റുകയോ ഡൗൺ ആകുകയോ ചെയ്താൽ, കൃത്യമായി ഒരു പ്ലഗിൻ മാത്രം തകരും. ബാക്കിയുള്ള ~19 എണ്ണം സേവനം തുടരും. ഇത്രയധികം സ്വതന്ത്ര ചലിക്കുന്ന ഭാഗങ്ങളുള്ളപ്പോൾ, ഓരോ പ്ലഗിന്റെയും ലോഗുകൾ കൈകൊണ്ട് പരിശോധിക്കുന്നതിന് പകരം എല്ലാം ഒരിടത്ത് നിന്ന് നിരീക്ഷിക്കുന്ന ഒരു സംവിധാനം ആവശ്യമായതിനാലാണ് `irt-api-health-monitor` നിലവിലുള്ളത്.

### സ്റ്റാക്ക്

- **WordPress** (കസ്റ്റം തീം, പേജ് ബിൽഡർ ഇല്ല): PHP ടെംപ്ലേറ്റുകൾ, വാനില JS/CSS
- **~20 കസ്റ്റം പ്ലഗിനുകൾ**, ഓരോ ഡാറ്റാ സ്രോതസ്സിനും ഒന്ന്, ഓരോന്നിനും അതിന്റേതായ ഫെച്ച്/കാഷ് ലെയർ
- സംഭരണത്തിനും ട്രാൻസിയന്റ് കാഷിംഗിനും **MySQL**; ലോക്കൽ ഡെവ്‌ന് Docker Compose
- ഒരു സമർപ്പിത പ്ലഗിൻ (`irt-dataset-schema`) വഴി Schema.org ഘടനാപരമായ ഡാറ്റ
- ഡാറ്റ അപ്‌ഡേറ്റുകളിൽ ഏതാണ്ട് തൽക്ഷണ സെർച്ച് എഞ്ചിൻ ഇൻഡെക്സിംഗിന് IndexNow ഇന്റഗ്രേഷൻ

### യഥാർത്ഥ ഇന്റഗ്രേഷൻ ഉദാഹരണങ്ങൾ

#### ഉദാഹരണം 1: മണ്ടി വിലകൾ പരിശോധിക്കുന്ന കർഷകൻ (CLI)
```bash
# Get wheat prices in Punjab
$ indiarealtime mandi --commodity wheat --state Punjab

Commodity  Market           State         City      Price (₹)  Unit
wheat      APMC Ludhiana    Punjab        Ludhiana  2450       Quintal
wheat      APMC Amritsar    Punjab        Amritsar  2420       Quintal
```

#### ഉദാഹരണം 2: പ്രൈസ് അലേർട്ട് ബോട്ട് നിർമ്മിക്കുന്ന സ്റ്റാർട്ടപ്പ് (Python)
```python
from indiarealtime import IndiaRealTime

irt = IndiaRealTime()

# Get current wheat prices
prices = irt.mandi_prices(commodity="wheat", state="Punjab", limit=5)

for price in prices:
    print(f"📊 {price.market}: ₹{price.price}/{price.unit}")
    
    # Alert if price drops below ₹2400
    if price.price < 2400:
        send_sms_alert(f"Wheat at {price.market} is ₹{price.price}!")
```

#### ഉദാഹരണം 3: ഇന്ധന വിലകൾ പരിശോധിക്കുന്ന ഡെലിവറി ആപ്പ് (REST API)
```javascript
// Fetch fuel prices for driver earnings calculation
fetch('http://localhost:5000/v1/fuel/prices?state=Maharashtra&type=diesel')
  .then(r => r.json())
  .then(data => {
    data.results.forEach(price => {
      console.log(`Diesel in ${price.city}: ₹${price.price}/L`);
    });
  });
```

#### ഉദാഹരണം 4: AQI സ്ക്രാപ്പ് ചെയ്യുന്ന ന്യൂസ് വെബ്‌സൈറ്റ് (Python)
```python
from indiarealtime import IndiaRealTime
import requests

irt = IndiaRealTime()
aqi = irt.air_quality(city="Delhi")

if aqi[0].aqi > 300:
    # Post alert headline
    headline = f"🚨 Air Quality SEVERE in {aqi[0].city}: AQI {aqi[0].aqi}"
    post_to_website(headline)
```

#### ഉദാഹരണം 5: നിരക്കുകൾ കാണിക്കുന്ന ഫിനാൻസ് ഡാഷ്ബോർഡ് (React)
```jsx
import { useState, useEffect } from 'react';

function CurrencyRates() {
  const [rates, setRates] = useState({});
  
  useEffect(() => {
    fetch('/api/v1/finance/currency?base=INR&symbols=USD,EUR,GBP')
      .then(r => r.json())
      .then(d => setRates(d.rates));
  }, []);
  
  return (
    <div>
      <h2>INR Exchange Rates</h2>
      <p>1 INR = ${rates.USD?.toFixed(4)} USD</p>
      <p>1 INR = €{rates.EUR?.toFixed(4)} EUR</p>
    </div>
  );
}
```

ഈ വെല്ലുവിളികളിൽ ഓരോന്നും അതിന്റേതായ പേജ് അർഹിക്കുന്നത്ര വലുതായി:

- **[മന:പൂർവ്വം പഴയ ഡാറ്റ നൽകൽ](notes/stale-cache-fallback.md)**: സർക്കാർ, എക്സ്ചേഞ്ച് API-കൾ വിശ്വസനീയമല്ല, എന്നിട്ടും സൈറ്റ് വിശ്വസനീയമായി കാണണം. ഒരു അപ്‌സ്ട്രീം API പരാജയപ്പെടുമ്പോൾ, ഞങ്ങൾ എറർ കാണിക്കുന്നതിനോ ഒന്നും കാണിക്കാതിരിക്കുന്നതിനോ പകരം അവസാനത്തെ നല്ല കാഷ് ചെയ്ത മൂല്യം നൽകുന്നു.
- **[ആക്സസിബിലിറ്റിയും നിറവും, രണ്ടും പ്രധാനം](notes/cvd-safe-aqi-colors.md)**: ഡാറ്റ എല്ലാവർക്കും ആക്സസ് ചെയ്യാവുന്നതാകാൻ ഓരോ അർത്ഥപൂർണ്ണമായ നിറവും WCAG കോൺട്രാസ്റ്റിനും കളർ-വിഷൻ-ഡെഫിഷ്യൻസി സിമുലേഷനും എതിരെ പരിശോധിക്കുന്നു.
- **[രണ്ട് ഭാഷകളിലും യോജിക്കുന്ന ഹാഷ്](notes/cross-language-hash-parity.md)**: PHP-യും JavaScript-ഉം ഇന്റിജർ ഓവർഫ്ലോയിൽ യോജിക്കുന്നില്ല, എന്നിട്ടും രചയിതാവ് ആട്രിബ്യൂഷൻ അവ യോജിക്കുന്നതിനെ ആശ്രയിച്ചിരിക്കുന്നു.
- **[ഓരോ സംസ്ഥാനത്തിനും റീറൈറ്റ്-റൂൾ regex ഇല്ലാതെ ലൊക്കേഷൻ റൂട്ടിംഗ്](notes/location-routing-without-regex.md)**: ഓരോ പ്രദേശത്തിനും ഒരു റീറൈറ്റ് റൂളിന് പകരം ഓരോ സംസ്ഥാന, നഗര പേജിനും ഒരൊറ്റ റൂട്ടിംഗ് പാത.
- **[~20 പ്ലഗിനുകൾ ഒരു മെയിന്റനബിലിറ്റി വാതുവെപ്പാണ്, സൗജന്യമല്ല](notes/plugin-per-source-tradeoff.md)**: ഫോൾട്ട് ഐസൊലേഷന്റെ വില എന്നാൽ എല്ലാം സ്ഥിരതയോടെ നിലനിർത്താൻ കൂടുതൽ വിസ്തൃതി വേണ്ടിവരും എന്നതാണ്.

## 👋 രചയിതാവിനെ കുറിച്ച്

ഈ റിപ്പോസിറ്ററി പ്രോജക്ടിന്റെ ഒരു അവലോകനമാണ്, സൈറ്റിന്റെ സോഴ്സ് അല്ല. WordPress കോഡ്‌ബേസ് ഇപ്പോൾ അടച്ചിരിക്കുന്നു. എന്നിരുന്നാലും, [API ലിസ്റ്റ്](API/), `scripts/` ഫോൾഡർ എന്നിവ PR-കൾക്കായി തുറന്നിരിക്കുന്നു - കാണാതായ API-കൾ, തിരുത്തലുകൾ, ഫെച്ചിന്റെ കൂടുതൽ ഉദാഹരണങ്ങൾ, എല്ലാം സ്വാഗതം ചെയ്യുന്നു.

മുകളിൽ പറഞ്ഞ ഏതെങ്കിലും പ്രശ്നത്തിന്റെ ഒരു പതിപ്പ് നിങ്ങൾ പരിഹരിച്ചിട്ടുണ്ടെങ്കിൽ (stale-cache fallback തന്ത്രങ്ങൾ, plugin-per-source ആർക്കിടെക്ചറുകൾ, CVD-safe കളർ സിസ്റ്റങ്ങൾ, cross-language hash parity), അല്ലെങ്കിൽ നിങ്ങൾ ഇപ്പോൾ അതേ മതിലിൽ തട്ടി നിൽക്കുകയാണെങ്കിൽ, ഒരു [ഡിസ്കഷൻ](https://github.com/padmarajnidagundi/indiarealtime-com/issues) തുറക്കുക. എനിക്ക് ശരിക്കും കുറിപ്പുകൾ താരതമ്യം ചെയ്യണം.

**സംഭാവനകൾ സ്വാഗതം:** പുതിയ ഡാറ്റാ സ്രോതസ്സുകൾ പ്ലഗിനുകളായി എങ്ങനെ ചേർക്കാമെന്നറിയാൻ [CONTRIBUTING.md](CONTRIBUTING.md) കാണുക, അല്ലെങ്കിൽ സഹായിക്കാനുള്ള മറ്റ് വഴികൾക്ക് [CONTRIBUTORS_GUIDE.md](CONTRIBUTORS_GUIDE.md) കാണുക.

നിങ്ങൾക്ക് ചോദ്യങ്ങളോ ആശയങ്ങളോ ഉണ്ടെങ്കിൽ, [GitHub Issues](https://github.com/padmarajnidagundi/indiarealtime-com/issues) വഴിയോ ഇമെയിൽ വഴിയോ ബന്ധപ്പെടുക.
