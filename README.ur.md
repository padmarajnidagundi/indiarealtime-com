## 📱 IndiaRealTime کے بارے میں

### مسئلہ کیا ہے

ڈیٹا پہلے سے موجود ہے اور زیادہ تر عوامی ہے۔ یہ صرف درجنوں مختلف سرکاری اور PSU پورٹلز پر بکھرا ہوا ہے، ہر ایک کا اپنا فارمیٹ، اپڈیٹ ہونے کا وقت، اور (اکثر) بھروسے کے مسائل۔

پنجاب میں منڈی بھاؤ دیکھنے والے کسان کو معلوم ہونا چاہیے کہ Agmarknet نام کی کوئی چیز موجود ہے۔ باہر جانا محفوظ ہے یا نہیں یہ جاننے والے کسی کو معلوم ہونا چاہیے کہ CPCB الگ ویب سائٹ پر، الگ فارمیٹ میں AQI شائع کرتا ہے۔ ایندھن کی قیمتیں روز بدلتی ہیں اور ریاست کے حساب سے مختلف ہوتی ہیں (مختلف VAT شرحیں)، لیکن ہر تیل کمپنی صرف اپنے اعداد، الگ الگ، صرف اُن شہروں کے لیے شائع کرتی ہے جہاں وہ خدمات دیتی ہے۔

اس کے لیے نیا ڈیٹا جمع کرنے کی ضرورت نہیں۔ صرف کسی کو جو پہلے سے عوامی ہے اسے لا کر، فارمیٹس کو یکساں بنا کر، منڈی بھاؤ، ایندھن کی قیمتیں، AQI، موسمی وارننگز وغیرہ کو ایک جگہ رکھنا ہے تاکہ کوئی شخص پانچ الگ سرکاری سائٹس کے پانچ ٹیب کھولنے کے بجائے چند سیکنڈوں میں دیکھ سکے۔ **یہی کمی IndiaRealTime پوری کرتا ہے۔**

### ہم کیا ٹریک کرتے ہیں

| زمرہ | مثالیں |
|---|---|
| قیمتیں | منڈی (زرعی اجناس)، ایندھن اور LPG ریاست/شہر کے حساب سے، قیمتی دھاتیں، کرنسی تبدیلی، میوچل فنڈ NAV، FD شرحیں، ٹول شرحیں |
| ماحول | ہوا کا معیار (AQI، CPCB بینڈز)، موسمی وارننگز، زلزلے کی وارننگز |
| شہری / وقت | بینک چھٹیاں، پن کوڈ لُک اَپ، ٹائم زون تبدیلی |
| ثقافت | پنچانگ اور مُہورت اوقات، ورت کیلنڈر، راشی فل |
| کھیل | لائیو کرکٹ اسکور |

کوریج شہر/ریاست کی سطح پر باریک بینی سے ہے، جہاں بھی بنیادی ڈیٹا اس کی اجازت دیتا ہے۔ مثال کے طور پر، ایندھن کی قیمتیں قومی اوسط نہیں، ہر شہر کے حساب سے ٹریک کی جاتی ہیں۔

اس کے پیچھے مفت ہندوستانی ڈیٹا APIs کی مکمل فہرست، اُن سرکاری APIs سمیت جو سائٹ ابھی استعمال نہیں کرتی، [API/](API/) میں ہے۔

### وزیٹرز کے لیے یہ کیسے کام کرتا ہے

- **مقام کے حساب سے براؤز کریں**: URLs `/state/city/category/` پیٹرن کی پیروی کرتے ہیں (مثلاً ایک ریاست کا صفحہ، پھر ایک شہر میں جانا، پھر ایندھن کی قیمتوں یا AQI جیسی کسی مخصوص کیٹیگری میں)۔ زیادہ تر کیٹیگریز قومی جائزہ اور شہر کے مخصوص تفصیلی صفحے دونوں شکلوں میں موجود ہیں۔
- **قیمتوں کا موازنہ کریں**: ایک پرائس-کمپیریزن ویو کسی چیز یا ایندھن کی قسم کو شہروں/ریاستوں میں ساتھ ساتھ دکھاتا ہے، ہر شہر کا صفحہ الگ کھولنے کے بجائے۔
- **کیلکولیٹرز**: ایک میٹلز کیلکولیٹر صرف فی گرام عدد دکھانے کے بجائے لائیو سونا/چاندی کی شرحوں کو وزن اور خالص پن کے حساب سے تبدیل کرتا ہے۔
- **شیئر کارڈز**: ڈیٹا صفحات سوشل پلیٹ فارمز کے لیے موزوں سائز کا شیئر کیے جانے والا امیج کارڈ (قیمت، تاریخ، ذریعہ) بناتے ہیں، تاکہ اسکرین شاٹ کے بغیر ہی کوئی حقیقت شیئر کی جا سکے۔
- **مصنفین کا حب**: ہر مضمون کو ایک حقیقی مصنف کے کریڈٹ کے ساتھ، اُن کے پروفائل صفحے سمیت، شائع کیا جاتا ہے، گمنام بائی لائن نہیں۔ `/authors/` سب کو فہرست میں دکھاتا ہے، `/author/<name>/` اُن کا شائع شدہ کام دکھاتا ہے۔

## 🏗️ ویب ایپلیکیشن کا آرکیٹیکچر

ہندوستان میں زیادہ تر "لائیو ڈیٹا" سائٹس یا تو دن میں ایک بار اسکریپ کر کے اسے ریئل ٹائم کہتی ہیں، یا ایک پیج-بلڈر تھیم پر درجنوں غیر متعلقہ ویجٹس تب تک شامل کرتی رہتی ہیں جب تک وہ برقرار رکھنے کے قابل نہ رہے۔ IndiaRealTime تقریباً 15 مختلف عوامی ڈیٹا ذرائع (سرکاری APIs، ایکسچینجز، موسمی اور زلزلے کے فیڈز) سے ڈیٹا لیتا ہے اور ہر ایک کو ایک مونولتھ کے بجائے اپنی چھوٹی، قابلِ آزمائش اکائی میں تبدیل کرتا ہے۔

اگر آپ ایک ڈیٹا-ایگریگیشن سائٹ، پلگ اِن پر مبنی آرکیٹیکچر، یا ایسا کچھ بنا رہے ہیں جہاں "اپ اسٹریم API آخرکار دھوکہ دے گی" ایک حقیقی ڈیزائن حد ہے، تو یہ آپ ہی کے لیے لکھا گیا ہے۔

### تکنیکی خاکہ

```
Public data sources (govt APIs, exchanges, weather/seismic feeds, ~15 total)
        │
        ▼
One WordPress plugin per source  ──►  WP-Cron fetch on its own schedule
  (fetch → validate → normalize)       (e.g. every 6h for commodities/AQI,
        │                               daily for fuel prices)
        ▼
WP transient cache (MySQL-backed)  ◄── on fetch failure, keep serving the
        │                               last good cached value instead of
        ▼                               erroring or showing nothing
Custom theme templates (PHP)
  render location/category pages
        │
        ▼
irt-dataset-schema → schema.org JSON-LD  +  irt-api-health-monitor watches
  (machine-readable structured data)       all fetchers from one dashboard
        │
        ▼
IndexNow ping on update → search engines re-crawl fresh data within minutes,
  not on their own schedule
```

### ڈیزائن فلسفہ

**ہر ڈیٹا ذریعہ ایک مکمل آزاد پلگ اِن ہے**، مشترکہ انجیشن پائپ لائن نہیں۔ ایک پلگ اِن کا اپنا فیچ شیڈول، کیش، اور ناکامی کا انتظام ہوتا ہے۔ اگر کوئی سرکاری API اپنا رسپانس فارمیٹ بدل دے یا بند ہو جائے، تو بالکل ایک پلگ اِن ٹوٹتا ہے۔ باقی ~19 خدمات دیتے رہتے ہیں۔ اتنے سارے آزاد چلتے پرزوں کے ساتھ، ہر پلگ اِن کے لاگز ہاتھ سے چیک کرنے کے بجائے سب کو ایک جگہ سے دیکھنے والا نظام درکار ہونے کی وجہ سے `irt-api-health-monitor` موجود ہے۔

### اسٹیک

- **WordPress** (کسٹم تھیم، کوئی پیج بلڈر نہیں): PHP ٹیمپلیٹس، وینیلا JS/CSS
- **~20 کسٹم پلگ اِنز**، ہر ڈیٹا ذریعے کے لیے ایک، ہر ایک کی اپنی فیچ/کیش لیئر
- اسٹوریج اور ٹرانزینٹ کیشنگ کے لیے **MySQL**؛ لوکل ڈیو کے لیے Docker Compose
- ایک مخصوص پلگ اِن (`irt-dataset-schema`) کے ذریعے Schema.org اسٹرکچرڈ ڈیٹا
- ڈیٹا اپڈیٹس پر تقریباً فوری سرچ انجن انڈیکسنگ کے لیے IndexNow انٹیگریشن

### حقیقی زندگی کی انٹیگریشن مثالیں

#### مثال 1: منڈی بھاؤ دیکھتا کسان (CLI)
```bash
# Get wheat prices in Punjab
$ indiarealtime mandi --commodity wheat --state Punjab

Commodity  Market           State         City      Price (₹)  Unit
wheat      APMC Ludhiana    Punjab        Ludhiana  2450       Quintal
wheat      APMC Amritsar    Punjab        Amritsar  2420       Quintal
```

#### مثال 2: پرائس الرٹ بوٹ بناتا اسٹارٹ اپ (Python)
```python
from indiarealtime import IndiaRealTime

irt = IndiaRealTime()

# Get current wheat prices
prices = irt.mandi_prices(commodity="wheat", state="Punjab", limit=5)

for price in prices:
    print(f"📊 {price.market}: ₹{price.price}/{price.unit}")
    
    # Alert if price drops below ₹2400
    if price.price < 2400:
        send_sms_alert(f"Wheat at {price.market} is ₹{price.price}!")
```

#### مثال 3: ایندھن کی قیمتیں چیک کرتی ڈیلیوری ایپ (REST API)
```javascript
// Fetch fuel prices for driver earnings calculation
fetch('http://localhost:5000/v1/fuel/prices?state=Maharashtra&type=diesel')
  .then(r => r.json())
  .then(data => {
    data.results.forEach(price => {
      console.log(`Diesel in ${price.city}: ₹${price.price}/L`);
    });
  });
```

#### مثال 4: AQI اسکریپ کرتی نیوز ویب سائٹ (Python)
```python
from indiarealtime import IndiaRealTime
import requests

irt = IndiaRealTime()
aqi = irt.air_quality(city="Delhi")

if aqi[0].aqi > 300:
    # Post alert headline
    headline = f"🚨 Air Quality SEVERE in {aqi[0].city}: AQI {aqi[0].aqi}"
    post_to_website(headline)
```

#### مثال 5: شرحیں دکھاتا فنانس ڈیش بورڈ (React)
```jsx
import { useState, useEffect } from 'react';

function CurrencyRates() {
  const [rates, setRates] = useState({});
  
  useEffect(() => {
    fetch('/api/v1/finance/currency?base=INR&symbols=USD,EUR,GBP')
      .then(r => r.json())
      .then(d => setRates(d.rates));
  }, []);
  
  return (
    <div>
      <h2>INR Exchange Rates</h2>
      <p>1 INR = ${rates.USD?.toFixed(4)} USD</p>
      <p>1 INR = €{rates.EUR?.toFixed(4)} EUR</p>
    </div>
  );
}
```

- **[ہر ریاست کے لیے ریرائٹ-رول regex کے بغیر لوکیشن روٹنگ](notes/location-routing-without-regex.md)**: ہر علاقے کے لیے ایک ریرائٹ رول کے بجائے ہر ریاست اور شہر کے صفحے کے لیے ایک ہی روٹنگ راستہ۔
- **[~20 پلگ اِنز ایک برقراری کا جوا ہے، مفت کی چیز نہیں](notes/plugin-per-source-tradeoff.md)**: فالٹ آئسولیشن کی قیمت کا مطلب ہے سب کچھ یکساں رکھنے کے لیے زیادہ سطحی رقبہ۔
